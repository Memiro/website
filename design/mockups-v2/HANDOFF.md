# Handoff: редизайн сайта Memiro

## Overview

Memiro — производство и интернет-магазин зеркал в Санкт-Петербурге (memiro.ru, работает с 2021 г.).
Пакет содержит редизайн четырёх экранов: главная страница, каталог с фильтрами, карточка товара,
мобильная версия главной. Задача — реализовать эти экраны в реальном коде.

Контент (тексты, цены, отзывы, категории, фотографии) взят с действующего сайта memiro.ru
и должен переноситься дословно — он согласован с заказчиком.

## About the Design Files

Файлы в папке `design/` — это **дизайн-референсы, собранные в HTML**. Это прототипы,
показывающие задуманный вид и поведение, а **не production-код для прямого копирования**.

Задача — воссоздать эти экраны в целевой кодовой базе средствами её собственного окружения
(React, Vue, Next.js, WordPress-тема и т.д.), используя принятые в проекте паттерны, роутинг
и библиотеки компонентов. Если окружения ещё нет — выбрать подходящий фреймворк и реализовать
дизайн в нём.

Технические детали прототипов, которые **не нужно переносить**:
- `.dc.html` — формат дизайн-инструмента; `support.js` — его рантайм. В продакшене не нужны.
- Вся стилизация в прототипах написана инлайновыми `style`-атрибутами (требование инструмента).
  В реальном проекте используйте принятый в нём подход: CSS-модули, Tailwind, styled-components и т.д.
- `ios-frame.jsx` — рамка iPhone только для демонстрации мобильного макета. В продакшене
  мобильная вёрстка должна быть обычным адаптивом главной страницы, а не отдельной страницей.
- Логика в прототипах хранит состояние в памяти компонента; корзина, отправка формы и фильтры
  должны быть подключены к реальному бэкенду.

## Fidelity

**High-fidelity.** Цвета, типографика, отступы, размеры и состояния наведения финальные —
воспроизводить попиксельно. Единственное исключение — фотографии (см. раздел Assets).

## Interactions & Behavior

### Навигация
- Логотип → главная. Пункты меню — якорные ссылки на секции главной (`#about`, `#order`, `#contacts`, `#lead`).
- Плитка категории в каталоге на главной → каталог с предустановленным фильтром
  (в прототипе — ссылки вида `?frame=v-rame`, `?form=krugloe`, `?backlight=s-podsvetkoj`,
  `?location=napolnoe`; фильтры каталога должны читаться из query-параметров).
- Карточка товара в сетке → страница товара.
- Хлебные крошки — на главную и в каталог.

### Главная — форма заявки
- Пилюли услуг: одиночный выбор; повторный клик по активной снимает выбор.
- При выбранной услуге под кнопкой показывается строка «Услуга: {название}».
- После отправки строка меняется на «Спасибо! Мы свяжемся с вами в ближайшее время.»
  (в прототипе `preventDefault`, без реального запроса).
- Обязательные поля: телефон и согласие на обработку данных. Валидацию нужно реализовать
  в целевом окружении — в прототипе её нет.

### Каталог — фильтрация
- Фильтры внутри группы объединяются по **ИЛИ**, группы между собой — по **И**.
- Пустая группа = ограничения нет.
- Ползунок цены отсекает товары дороже выбранного значения (верхняя граница).
- **Счётчики у вариантов** считаются с исключением своей же группы: для варианта группы `X`
  учитываются все активные фильтры, кроме фильтров самой группы `X`, плюс ограничение по цене.
  Так пользователь видит, сколько добавится при включении варианта.
- Сортировка: Популярные (исходный порядок), Сначала дешёвые (по возрастанию цены),
  Сначала дорогие (по убыванию).
- Чипы активных фильтров рендерятся по всем группам, клик снимает конкретное значение.
- «Сбросить» / «Сбросить фильтры» очищают выбор и возвращают цену на максимум (40 000).
- При нулевом результате сетка заменяется пустым состоянием.
- Склонение слова «товар» по числу: 1 — товар; 2–4 — товара; 0, 5–20 — товаров;
  учитывать исключение 11–14 → товаров.

### Карточка товара — конфигуратор
- Цена = (база 10 706 + надбавка за размер + надбавка за подсветку + надбавка за крепление) × количество.
- Зачёркнутая «старая» цена = итог × 1.18, округлённый до десятков.
- Количество: от 1 до 9.
- Кнопка корзины после добавления меняет текст на «Добавлено в корзину», счётчик в шапке
  увеличивается на выбранное количество.
- Клик по миниатюре меняет основное фото.
- Табы переключают контент без перезагрузки; вкладка «Характеристики» отражает текущую
  конфигурацию (размер, подсветка, крепление).
- Для варианта «Свой размер» в характеристиках выводится «по вашим размерам».

### Состояния наведения
- Ссылки: цвет → `accent` (`#3C5B6E`). Задать глобально для `a` и `a:hover`.
- Тёмные кнопки: фон → `accent`.
- Кнопки-обводки: граница → `text/primary`; на тёмном фоне — инверсия (фон светлый, текст тёмный).
- Карточки товара: граница → `border/control`.
- Плитки каталога: `opacity: 0.94`.
- Иконочные кнопки: граница и цвет → `text/primary`.

### Отсутствующие состояния
В прототипах **нет**: загрузки, ошибок сети, пустой корзины, оформления заказа, авторизации,
пагинации каталога (все товары на одной странице). Их нужно спроектировать/добавить при реализации.

## State Management

**Главная / мобильная:** `service` (выбранная услуга, nullable), `sent` (форма отправлена),
`menuOpen` (только мобильная).

**Каталог:** `active` — объект `{ frame: [], form: [], light: [], place: [] }` с массивами
выбранных значений; `priceMax` (число, по умолчанию 40000); `sort` (строка).
Отфильтрованный и отсортированный список — производное значение, не состояние.

**Карточка товара:** `img` (индекс фото), `size`, `light`, `mount` (индексы выбранных опций),
`qty` (1–9), `tab` (активная вкладка), `cart` (количество в корзине).
Цена — производное значение.

**Данные.** В прототипах товары захардкожены массивом. В продакшене — из API/CMS. Поля товара:
`name`, `price`, `img`, `frame`, `form`, `light`, `place`, `size`, `badge`.
Каталог содержит 10 товаров, из них 4 реальных (Kov Black / Gold / White, Halo Led) —
остальные (Orbis, Puro, Alto, Arco, Lumen, Kov Shelf) придуманы для наполнения сетки
и должны быть заменены реальным ассортиментом.

## Assets

**Фотографии.** Все изображения — прямые ссылки на действующий сайт
(`https://memiro.ru/wp-content/themes/memiro/images/…`, аватары отзывов —
`https://memiro.ru/wp-content/uploads/2026/01/…`), формат AVIF.

Важно: сервер memiro.ru не отдаёт файлы для скачивания сторонним клиентам (CORS),
поэтому изображения в пакет не вложены и прототипы требуют интернета. При реализации
нужно получить исходники у заказчика — на сайте их немного (около 10 кадров) и часть
имеет низкое разрешение (например, 872×578), для крупных блоков нужны новые снимки.

**Иконки.** Все иконки — инлайновые SVG в 24×24 viewBox, отрисованы в этом проекте:
корзина, Telegram, WhatsApp, гамбургер. Общие параметры: `fill: none`, `stroke: currentColor`,
`stroke-width: 1.7–1.8`, `stroke-linecap: square`, `stroke-linejoin: miter`.
Рендер-размер 16–20px. Квадратные концы линий — часть стиля, сохранить.

**Шрифт.** Golos Text из Google Fonts:
`https://fonts.googleapis.com/css2?family=Golos+Text:wght@400;500;600;700;800&display=swap`.
Лицензия OFL, можно self-host.

**Звёзды рейтинга** — текстовые символы `★★★★★` с трекингом 0.3em, не иконки.

  Memiro - Карточка товара.dc.html   — страница товара с конфигуратором

Чтобы открыть прототип: положить все файлы в одну папку и открыть любой `.dc.html`
в браузере (нужен интернет — шрифты и фото подгружаются с внешних адресов).

Структура каждого файла: разметка находится внутри тега `<x-dc>`, логика — в теге
`<script data-dc-script>` в виде класса `Component` с методом `renderVals()`, который
возвращает значения для подстановок `{{ … }}` в разметке. Циклы — `<sc-for list as>`,
условия — `<sc-if value>`. Читать эти файлы стоит как декларативное описание вида и поведения.
