# Дизайн memiro (тикет 02)

Статические макеты, продакшен-кода здесь нет. Фотографии подгружаются со старого сайта memiro.ru, поэтому для просмотра нужен интернет.

## Как смотреть

Открыть файлы в браузере напрямую или поднять локальный сервер:

```bash
python3 -m http.server 8080 --directory design
# затем http://localhost:8080/directions.html
```

## Состав

- `directions.html` — три визуальных направления на выбор владельца:
  1. **Свет** (рекомендуем) — холодная светлая галерея, Manrope, графит, акцент #2F5DA8
  2. **Глубина** — тёмное ателье, Unbounded + Onest, янтарный акцент цвета LED-подсветки
  3. **Графика** — монохромная плакатная вёрстка, Commissioner, кобальт, радиус 0
- `mockups/` — макеты страниц в направлении «Свет»:
  - `home.html` — главная (hero, акция, категории, популярное, шаги заказа, отзывы, CTA)
  - `catalog.html` — каталог с фильтрами, сортировкой, бейджами «Акция» / «Нет в наличии»
  - `product.html` — карточка товара: галерея, характеристики, калькулятор размера (имитация)
  - `styles.css` — токены направления «Свет» (цвет, шрифт, радиусы, компоненты)

## Статус

Ожидает выбора направления и утверждения владельцем. Если выбор падёт на «Глубину» или
«Графику», структура макетов сохраняется, перекрашиваются токены.

Дизайн-параметры (taste-skill): `DESIGN_VARIANCE 7 / MOTION_INTENSITY 6 / VISUAL_DENSITY 3`.
Скролл-анимации в макетах обозначены эскизно (reveal); полноценная моушен-система делается в тикетах 04–05.
