# Дизайн memiro (тикет 02)

Статические макеты, продакшен-кода здесь нет. Фотографии подгружаются со старого сайта memiro.ru, поэтому для просмотра нужен интернет.

## Как смотреть

Открыть файлы в браузере напрямую или поднять локальный сервер:

```bash
python3 -m http.server 8080 --directory design
# затем http://localhost:8080/directions.html
```

## Состав

- `directions.html` — пятнадцать визуальных направлений на выбор владельца:
  1. **Свет** (ВЫБРАН владельцем 2026-08-19) — холодная светлая галерея, Manrope, графит, акцент #2F5DA8
  2. **Глубина** — тёмное ателье, Unbounded + Onest, янтарный акцент цвета LED-подсветки
  3. **Графика** — монохромная плакатная вёрстка, Commissioner, кобальт, радиус 0
  4. **Хром** — тёмный графит, хром-градиентные заголовки Tektur, металлические кнопки
  5. **Плакат** — брутализм: Rubik Mono One капсом, рамки 3px, кислотный #86E300
  6. **Салон** — интерьерный люкс: лесной зелёный, Playfair Display, янтарь #D9A441
  7. **Мягкость** — пастель: лаванда #8F7AD6, Comfortaa + Nunito, радиус 32px
  8. **Арка** — арочные обрезки фото, терракота #B4552F + прохладный серый, Tenor Sans
  9. **Пунш** — белый + чёрный контур + малина #F22E6B, Rubik 900 капсом
  10. **Витрина** — люкс-минимал (207ouest/Haus): монохром, Jost 300 капсом, радиус 0
  11. **Полночь** — тёмное техно (Noon): сине-чёрный, электрик #4C7DFF, Inter Tight
  12. **Штиль** — спокойное (Calm): туманно-голубой, Alegreya Sans, вода #3B82C4
  13. **Афиша** — дерзкое (Snacklins): Oswald капсом поверх фото, жёлтый #FFD23F

- `mockups/` — УТВЕРЖДЁННЫЕ макеты страниц в направлении «Свет»:
  - `home.html` — главная (hero, акция, категории, популярное, шаги заказа, отзывы, CTA)
  - `catalog.html` — каталог с фильтрами, сортировкой, бейджами «Акция» / «Нет в наличии»

- `heroes/` — исторические hero-эксперименты (8 вариантов, вход `heroes/index.html`); в работу не идут
