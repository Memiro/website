# Дизайн memiro

**Действующий комплект — `mockups-v2/`** (handoff-пакет редизайна, 2026-08-20, тикет 12).
Направление «Свет» (`directions.html`, `mockups/`, тикет 02) выведено из работы и оставлено
как история: по нему собраны тикеты 04–05, поэтому старый вид кода объясняется именно им.

Правило приоритетов при расхождении макета с кодом — ADR-0004: юридические требования,
затем SEO-политика и доменная модель, и только потом попиксельная верность макету.

Статические макеты, продакшен-кода здесь нет. Фотографии подгружаются со старого сайта memiro.ru, поэтому для просмотра нужен интернет.

## Как смотреть

Открыть файлы в браузере напрямую или поднять локальный сервер:

```bash
python3 -m http.server 8080 --directory design
# затем http://localhost:8080/directions.html
```
