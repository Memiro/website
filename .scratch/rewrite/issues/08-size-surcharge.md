# 08: Наценка за размер

**What to build:** Крупное зеркало дорожает по ступеням с первого дня (ADR-0010, user story 5): ступени наценки — часть агрегата PricingSettings, коэффициент перемножается с коэффициентом формы и множит только помеченные значения справочника; всё внутри того же единственного сервиса расчёта, сквозь `POST /api/calculate`. Границы ступеней и решения владельца — по ADR-0010 и памятке о наценке за размер.

**Blocked by:** 06 (walking skeleton)

**Status:** ready-for-agent

- [ ] Ступени наценки живут внутри PricingSettings (миграция + гейтвей + фабрики тестов)
- [ ] Коэффициент перемножается с формой и применяется только к помеченным значениям — юнит-тесты называют оба правила
- [ ] Интеграционный тест: одно и то же зеркало в разных размерных ступенях даёт разные цены через эндпоинт
- [ ] Расчёт без ступеней (пустой набор) работает как раньше — наценка не обязательна
