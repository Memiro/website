# 21: Заявки в админке

**What to build:** Менеджер и владелец разбирают заявки в админке: changelist с фильтрами и поиском, просмотр заявки с позициями-слепками (конфигурация и цена на момент отправки — читаются и через год при других тарифах, user story 19–20). Слепок неприкосновенен: пересчёта задним числом нет, редактирование позиций закрыто. Рабочие глаголы по заявке (если появятся — например, «обработана») — действиями админки через интеракторы, не CRUD.

**Blocked by:** 17 (мост админки)

**Status:** ready-for-agent

- [ ] Changelist заявок с фильтрами по дате и поиском по контактам
- [ ] Просмотр заявки показывает каждую позицию отдельным ТЗ из слепка
- [ ] Слепок не редактируется из админки; форма позиций закрыта на запись
- [ ] Цены в просмотре — из слепка, не из живого расчёта (тест на зеркале)
