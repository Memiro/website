# 14: Каталог, карточка и остров калькулятора

**What to build:** Покупатель открывает быстрые серверные страницы каталога и карточки (user story 18) и настраивает зеркало в калькуляторе: остров Vue (`client:visible`) шлёт выбор на `POST /api/calculate` и показывает цену сразу — итог и дельты выбранных добавок («подсветка +11 500 ₽») без устройства цены (ADR-0005, ADR-0007, user stories 13–15). Калькулятор открывается на первом подходящем предпосчитанном варианте (решение 62). Погашенная цена — карточка без цены, но с конструктором (ADR-0008). Вердикты отображаются: за пределом производства — приглашение оставить пожелание, а не отказ. Состояние калькулятора живёт в его компоненте.

**Blocked by:** 12 (`browse_catalog` API), 13 (скелет фронта)

**Status:** ready-for-agent

- [ ] Страницы каталога и карточки рендерятся SSR по слагам из API
- [ ] Остров калькулятора считает на сервере по актуальным тарифам; цена совпадает с ответом эндпоинта
- [ ] Дельты добавок показаны; ставки/коэффициенты/статьи нигде не всплывают
- [ ] Калькулятор открыт на первом подходящем варианте; переключение варианта меняет конфигурацию
- [ ] Вердикты BEYOND_LIMITS и HIDDEN имеют внятное отображение
