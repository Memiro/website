# 18: Конструктор вариантов в карточке товара

**What to build:** Владелец собирает предпосчитанные варианты конструктором в карточке товара админки (ADR-0011, user story 8): видит живую цену собранного до сохранения, добавляет следующий, правит, удаляет, размножает по размеру — поштучными командами агрегата из тикета 09, без inline-таблицы вариантов. Живую цену показывает та же точка, что запишет её варианту — владельческий вопрос без гейтов (решение 63). Дубликат по размеру+значениям отклоняется до сохранения. Порядок вариантов правится владельцем. Товар и его публикация тоже правятся здесь — карточка собирается в одном месте.

**Blocked by:** 09 (команды вариантов), 17 (мост админки)

**Status:** ready-for-agent

- [ ] Цена собранного видна до сохранения и совпадает с тем, что запишется варианту
- [ ] Добавление/правка/удаление/размножение по размеру работают из карточки; «цена от» обновляется
- [ ] Инлайн-таблицы вариантов нет; каждая операция — поштучная команда агрегата
- [ ] Дубликат по размеру+значениям показывает отказ, ничего не сохранив
- [ ] Порядок вариантов сохраняется и виден в API карточки
