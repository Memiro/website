# 23: Книга xlsx

**What to build:** Владелец собирает книгу xlsx по товару из живой базы и проверяет расчёт руками против канона на рабочем столе (user story 9): интерактор экспорта книги над тем же единственным сервисом расчёта — второй реализации расчёта в репозитории нет (решение 29); openpyxl-рендер — адаптер; запуск — команда собственного CLI (`memiro workbook build`), не management command. Книга показывает полный breakdown по статьям — это внутренний потребитель, забор приватности на неё не распространяется.

**Blocked by:** 07 (гейты и вердикты), 08 (наценка за размер)

**Status:** ready-for-agent

- [ ] Команда CLI собирает книгу по товару из живой базы
- [ ] Числа книги совпадают с ответом сервиса расчёта на тех же входах (тест сверки)
- [ ] Наценка за размер и формула по единицам расхода видны в книге статьями
- [ ] openpyxl заперт в адаптере; домен и приложение о нём не знают
