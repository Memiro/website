# 22: Контент в админке

**What to build:** Владелец заводит посадочные, работы, вопросы-ответы и контакты студии как раньше (user story 11). Граница — «есть инварианты vs нет» (решение 15): контент без правил (работы, отзывы, FAQ, контакты студии, легаси-URL) — прямой CRUD мимо домена, доменных сущностей не получает (DTO + read-гейтвей, решение 49); посадочная с условиями — агрегат Landing через корневой интерактор inline-формсетом (одна транзакция, полная замена условий). Контакты студии — сущность с известным id, редирект на единственный объект. Таблицы контента — alembic-миграцией, зеркала под тест дрейфа.

**Blocked by:** 17 (мост админки)

**Status:** ready-for-agent

- [ ] Работы, отзывы, FAQ, контакты, легаси-URL заводятся прямым CRUD; сущностей в домене для них нет
- [ ] Посадочная с условиями сохраняется одной транзакцией через интерактор; бизнес-отказ ничего не сохраняет
- [ ] Контакты студии — редирект с changelist на единственный объект
- [ ] Тест дрейфа покрывает новые зеркала контента
