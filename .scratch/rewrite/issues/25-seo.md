# 25: SEO

**What to build:** Поисковик получает sitemap, robots, meta/OG, canonical, JSON-LD и 301 со старых адресов — переезд не обнуляет индексацию (user story 21, ADR-0003). Разделение по решению 37: бэк отдаёт данные (эндпоинт записей sitemap, список легаси-редиректов из справочника легаси-URL), фронт рендерит sitemap.xml, robots.txt, мета-теги, разметку JSON-LD и выполняет 301. SEO переживает будущую смену стека при сохранении URL (решение 48).

**Blocked by:** 14 (каталог и карточка), 22 (легаси-URL в админке), 24 (контент-страницы)

**Status:** ready-for-agent

- [ ] sitemap.xml собирается из данных бэка и покрывает каталог, карточки, посадочные и контент-страницы
- [ ] Легаси-адрес из справочника отвечает 301 на новый URL
- [ ] Карточка товара несёт canonical, meta/OG и JSON-LD продукта
- [ ] robots.txt отдаётся; неопубликованное в sitemap не попадает
