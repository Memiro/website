# 12: `browse_catalog` API

**What to build:** Витрина может спросить у бэка каталог: список категорий, товары категории с «ценой от», данные карточки товара (атрибуты, варианты в порядке владельца, фото-ключи, слаги). Наружу — только опубликованное; гейт погашенной цены прячет цену, не карточку (ADR-0008). Идентификаторы в публичных URL — слаги. Read-путь по §7: DTO + read-гейтвей + read-интеракторы, без доменных сущностей там, где нет правил.

**Blocked by:** 09 (варианты и «цена от»)

**Status:** ready-for-agent

- [ ] Эндпоинты категорий, списка товаров и карточки отвечают по слагам
- [ ] Неопубликованный товар невидим снаружи (тест), опубликованный с погашенной ценой виден без цены
- [ ] «Цена от» в списке — из производного поля, без пересчёта на чтении
- [ ] Варианты карточки приходят в порядке владельца
- [ ] В публичном JSON каталога нет устройства цены (ставок, коэффициентов, статей)
