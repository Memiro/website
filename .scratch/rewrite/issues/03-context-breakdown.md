# 03: Разбор CONTEXT.md на страницы сущностей и VO

**What to build:** Доменная правда разложена по шаблонам §16.2: страницы сущностей (docs/entities/) и страницы value objects (docs/value-objects/) для корней и величин из решений 22 и 34; сам CONTEXT.md остаётся коротким входом со ссылками. Тонкие правила переезжают без ревизии: дробный `Decimal` в количестве, «отсутствие признака» — значение справочника (`marks_absence`), пустота = «владелец не дошёл» и глушит расчёт. Состав справочника учитывает ответы владельца из тикета 01.

**Blocked by:** 01 (решения владельца по справочнику), 02 (учредительные документы)

**Status:** resolved

- [x] Страница есть у каждого VO величин: Millimeters, Dimensions, Money, Rate, Area, Perimeter, Quotation
