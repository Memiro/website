# Шесть посадочных из макета v2 (тикет 14)

Плитки главной и корня каталога набираются из посадочных, а не из
категорий: категория — тип товара, «круглое» и «с подсветкой» ей не
выражаются. Шесть плиток макета заводятся как данные, не как код.

## Запуск

```sh
uv run python .scratch/new-site/landings/create_landings.py
```

Прогон идемпотентен: посадочная с таким слагом пропускается — тексты и
обложки владелец правит в админке, и переписывать их скриптом нельзя.

## Что заводится

| Слаг | Условие |
|---|---|
| `/zerkala-s-podsvetkoy/` | подсветка = С подсветкой |
| `/kruglye-zerkala/` | форма = Круглое |
| `/figurnye-zerkala/` | форма = Фигурное |
| `/zerkala-v-rame/` | рама = В раме |
| `/zerkala-bez-ramy/` | рама = Без рамы |
| `/zerkala-napolnye/` | расположение = Напольное |

Посадочные создаются опубликованными: пустая посадочная витрине не
вредит — она пропускается и в плитках, и в sitemap, и появляется сама,
когда владелец опубликует подходящие товары (после переноса все 88
лежат черновиками).

## Что остаётся владельцу

- **Вычитать тексты.** `title`, `description` и текст страницы написаны
  по данным каталога, а не с его слов.
- **Поставить обложки плиток** — поле «обложка плитки» в админке
  посадочной. Пока оно пустое, плитка берёт фото первого товара
  посадочной, и кадр получается случайным; макет ставит конкретный.
