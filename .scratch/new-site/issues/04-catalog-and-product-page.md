# 04 — Каталог и карточка товара

**What to build:** Страница каталога и карточка товара по утверждённым макетам «Света». Фильтры строятся из атрибутов категории автоматически: ИЛИ внутри атрибута, И между; мгновенное применение на десктопе (левый сайдбар), drawer с кнопкой «Показать N товаров» на мобиле; счётчики значений, блок применённых фильтров с крестиками и «Сбросить всё». Сортировка: цена ↑↓, популярность, новинки. Пагинация — «Показать ещё» поверх настоящих `?page=n` с `<a>`-ссылками и self-canonical. Карточка: галерея, характеристики, цена «от», кнопка заявки. Состояния «нет в наличии» нет — всё под заказ.

**Blocked by:** 03 — Товары: модель каталога, атрибуты, админка

**Status:** ready-for-human

- [x] Каталог выводит товары из БД; фильтры из атрибутов работают (ИЛИ/И), счётчики и блок применённых фильтров на месте
- [x] Пустые комбинации фильтров отдают 404; фасетные URL канонизируются на категорию
- [x] Пагинация: «Показать ещё» + номера страниц, `?page=n` доступны как обычные ссылки, self-canonical
- [x] Карточка: галерея, характеристики из атрибутов, цена «от X ₽»
- [x] Вёрстка по макетам, адаптив; мобильные фильтры — drawer
- [x] HTTP-тесты: каталог содержит товары, фильтр отсекает лишнее, карточка отдаёт данные, ?page=2 работает

## Comments

2026-08-19 (agent, из ревью тикета 02): хвосты дизайна, не закрытые макетами, решить здесь:
1) мобильное меню («Меню»-пилюля без раскрытого состояния) и мобильные фильтры-drawer;
2) показать «материал/цвет рамы» в карточке товара В РАМЕ (в макете только безрамный Halo Moon);
3) размер страницы пагинации каталога (в макете условные 4 страницы).

2026-08-19 (agent, грилинг): UX фильтров — по Baymard (ресёрч в сессии), SEO-правила пагинации и фасетов — ADR-0003.

2026-08-19 (agent, реализация): готово, 24 новых HTTP/юнит-теста зелёные. Решения по хвостам:
1) мобильное меню — раскрывающаяся панель под шапкой («Меню»-пилюля, aria-expanded);
2) атрибуты рамы (материал/цвет) отдельно не хардкодятся — карточка рендерит ВСЕ атрибуты товара, у товаров в раме они появляются автоматически;
3) размер страницы пагинации — 12 (делится на 3 и 2 колонки сетки).
Прочее: URL — `/catalog/<категория>/<товар>/`; значения фильтров в querystring — pk значений справочника (`?forma=3`), булевы — `1/0`; посторонние параметры (utm) игнорируются, мусорные значения фильтров — 404; сортировка `?sort=price|-price|new`, дефолт «популярные»; у Product появился `created_at` (миграция 0002) для «новинок»; Manrope самохостится woff2-сабсетами (задел под тикет 10 — без Google Fonts в проде); счётчик в кнопке drawer обновляется fetch'ем самой страницы каталога, без отдельного API; «Показать ещё» — прогрессивное улучшение над `<a href="?page=n">`. Кнопки «В корзину»/«В избранное» — заглушки с data-атрибутами под тикет 07.

2026-08-19 (agent, код-ревью): правки внесены (глоссарий: класс `.sku` → `.article`, «фасет/характеристики» из докстрингов; склонение и блокировка кнопки drawer на пустой комбинации; фолбэк главного фото в галерее; canonical обновляется при «Показать ещё»; контакты — в контекст-процессоре). Зафиксированные решения:
- `/catalog/` при единственной видимой категории редиректит в неё, при нескольких — список; в тикете не оговаривалось, принято здесь.
- Чипсы-пресеты из макета каталога («Все / С подсветкой / …») заменены блоком применённых фильтров — так велел сам тикет; пресеты никуда не переносятся, при желании владельца их роль сыграют посадочные (тикет 09).
- robots.txt и Clean-param из ADR-0003 — тикет 09, здесь только canonical.
