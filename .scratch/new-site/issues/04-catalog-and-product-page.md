# 04 — Каталог и карточка товара

**What to build:** Первый «настоящий» кусок сайта: страница каталога и карточка товара по утверждённым макетам, с реальными товарами из базы. Каталог — с фильтрами по характеристикам; карточка — галерея, характеристики, цена. Скролл-анимации и микровзаимодействия по taste-скиллам, мобильная версия.

**Blocked by:** 01 — Скаффолдинг Django-проекта, 02 — Дизайн: направления и макеты ключевых страниц, 03 — Товары: модель, админка, миграция со старого сайта

**Status:** ready-for-agent

- [ ] Страница каталога выводит товары из БД, фильтры работают
- [ ] Карточка товара: галерея, характеристики, цена, состояние «нет в наличии»
- [ ] Вёрстка соответствует утверждённым макетам, адаптив под мобильные
- [ ] HTTP-тесты: каталог содержит товары, фильтр отсекает лишнее, карточка отдаёт данные товара
