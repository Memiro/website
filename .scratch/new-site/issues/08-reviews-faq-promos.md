# 08 — Отзывы, FAQ и акции из админки

**What to build:** Маркетинговый контент из админки: отзывы, FAQ и акции создаются/редактируются владельцем и отображаются на сайте. Отзывы — только настоящие, заносятся вручную с указанием источника (например, Avito); разметка рейтинга в schema.org подключается только при реальных отзывах (иначе риск санкций поисковиков — см. тикет 09).

**Blocked by:** 05 — Главная, статические страницы и «Наши работы»

**Status:** ready-for-agent

- [ ] Отзывы (текст, автор, источник), FAQ и акции — отдельные разделы админки
- [ ] Опубликованные записи появляются на сайте, скрытые — нет
- [ ] Блок акции на главной управляется из админки
- [ ] HTTP-тесты: созданная запись видна, снятая с публикации — исчезает
