# 08 — Отзывы, FAQ и акции из админки

**What to build:** Маркетинговый контент из админки: отзывы, FAQ и акции создаются/редактируются владельцем и отображаются на сайте. Отзывы — только настоящие, заносятся вручную с указанием источника (например, Avito); разметка рейтинга в schema.org подключается только при реальных отзывах (иначе риск санкций поисковиков — см. тикет 09).

**Blocked by:** 05 — Главная, статические страницы и «Наши работы»

**Status:** ready-for-human

- [x] Отзывы (текст, автор, источник), FAQ и акции — отдельные разделы админки — *`memiro.content`: `Review`, `FaqEntry`, `Promo`*
- [x] Опубликованные записи появляются на сайте, скрытые — нет — *все опубликованные отзывы и вопросы выходят на главную без потолка*
- [x] Блок акции на главной управляется из админки — *заголовок и описание блока — из `Promo`; лента товаров набирается флагом «акция» у товара (тикет 03)*
- [x] HTTP-тесты: созданная запись видна, снятая с публикации — исчезает — *`tests/test_marketing.py`*

## Comments

### Решения по ходу

- **Блок акции без опубликованной акции не рисуется вовсе**, даже если у товаров стоит флаг «акция». Иначе критерий «управляется из админки» не выполняется: заголовок «Специальные цены» оставался бы зашитым в шаблон. Чтобы переезд не сломал уже отмеченные товары, миграция `content.0003` заводит акцию с прежним заголовком, если такие товары в базе есть.
- **На главную выходит первая опубликованная акция по полю «порядок»** — блок в макете один. Пояснение про это и про набор товаров стоит в форме акции в админке.
- **FAQ живёт секцией на главной** (аккордеон `<details>`): в handoff-пакете такой секции нет, вид выведен из его токенов (границы 1px, нулевые скругления, вертикальный ритм) по ADR-0004.
- **Оценка отзыва хранится (`rating`), но schema.org-разметки нет** — она приезжает тикетом 09, и только по реальным отзывам.
- **Источник отзыва — свободный текст, не справочник**: новая площадка (Яндекс, 2ГИС, VK) не должна ждать разработчика. Тот же принцип, что у атрибутов каталога.
- **Ссылка «Смотреть все →» ведёт на витрину Avito** — адрес лежит в `context_processors.CONTACTS` рядом с остальными контактами студии.

### Не проверено глазами

Визуальный цикл прогнать не удалось: в системе сейчас нет Firefox, headless-снимок через Яндекс.Браузер зависает. Вёрстка отзывов и FAQ проверена только по разметке и токенам пакета — перед показом владельцу нужен скриншот.
