# 13 — Фильтр по цене в каталоге

**What to build:** Сужение выдачи каталога по цене — единственный фильтр, который строится не из атрибутов категории, а из самого поля товара. В макете редизайна это ползунок с верхней границей (`design/mockups-v2/Memiro - Каталог.dc.html`, блок под группами фильтров).

**Blocked by:** 12 — Редизайн витрины: новый визуальный язык

**Status:** needs-triage

## Что решить до реализации

- **Форма контроля.** Ползунок из макета задаёт только верхнюю границу и не даёт ввести число руками. Альтернатива — два поля «от» и «до»: точнее, доступнее с клавиатуры и переживает категории с разным разбросом цен. Решение за владельцем, вид подгоняется под токены пакета.
- **Границы диапазона.** В макете зашиты 3 000–40 000 ₽. У каждой категории разброс свой, а после переноса 88 товаров (тикет 11) он изменится — границы должны считаться из данных категории, а не жить в вёрстке.
- **SEO.** Цена добавляет в URL ещё один фасетный параметр. По ADR-0003 он закрывается от индексации наравне с остальными: robots, canonical на категорию, Clean-param для Яндекса. Проверить, что новый параметр действительно попал в закрывающие правила тикета 09.
- **Взаимодействие со счётчиками.** Счётчики значений атрибутов считаются с исключением своей группы; ограничение по цене должно учитываться во всех счётчиках, включая свою группу — цена группой не является.
- **Пустой результат.** Комбинация «фильтры + цена», не находящая ничего, должна вести себя как остальные пустые комбинации (сейчас — 404, тикет 04).

## Acceptance criteria

- [ ] Границы диапазона считаются из опубликованных товаров категории, в вёрстке не зашиты
- [ ] Фильтр по цене комбинируется с фильтрами атрибутов (И между ними) и попадает в чипы применённых фильтров с крестиком
- [ ] Счётчики значений атрибутов учитывают выбранный диапазон цен
- [ ] Параметр цены закрыт от индексации наравне с прочими фасетными (ADR-0003)
- [ ] Контрол доступен с клавиатуры, у него есть подпись, значение читается скринридером
- [ ] HTTP-тесты: диапазон сужает выдачу; пустая комбинация ведёт себя как остальные пустые
