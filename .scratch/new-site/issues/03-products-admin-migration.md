# 03 — Товары: модель каталога, атрибуты, админка

**What to build:** Ядро каталога в базе и админке, спроектированное от домена (`CONTEXT.md`), без оглядки на сущности старого сайта. Общие поля товара — колонками (название, слаг, цена «от», описание, артикул, фото малое+большое, галерея, флаги популярное/акция, порядок); фильтруемые характеристики — справочник атрибутов с привязкой к категории (ADR-0002): владелец заводит новую категорию, её атрибуты и значения без разработчика. Наличия в модели нет — всё под заказ. Перенос данных со старого сайта — НЕ здесь (тикет 11).

**Blocked by:** 01 — Скаффолдинг Django-проекта

**Status:** ready-for-human

- [x] Модель: категория (плоская), товар с общими полями-колонками, справочник атрибутов/значений с привязкой к категории; миграции применяются с нуля
- [x] Атрибуты простых типов: выбор из списка, да/нет, число
- [x] Категория считается видимой только при наличии опубликованных товаров
- [x] Админка: товары (инлайны фото/галереи, превью), категории, атрибуты и значения — всё редактируется владельцем
- [x] Цена обязательна у каждого товара (валидация), режима «цена по запросу» нет
- [x] HTTP-тесты: товар создаётся и валидируется; атрибуты категории доступны товару; чужие — нет
