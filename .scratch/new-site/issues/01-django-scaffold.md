# 01 — Скаффолдинг Django-проекта

**What to build:** Фундамент проекта: Django-проект запускается локально, пустая главная страница отдаётся браузеру, тестовая инфраструктура работает, django-modern-rest подключён и отвечает на пробный JSON-эндпоинт.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] `runserver` поднимает сайт локально, главная отдаёт HTML-заглушку
- [ ] Тестовый раннер работает, первый HTTP-тест (главная отвечает 200) зелёный
- [ ] django-modern-rest подключён, пробный типизированный эндпоинт отвечает и отражён в OpenAPI-схеме
- [ ] Админка открывается, суперпользователь создаётся
- [ ] База: SQLite для разработки, конфигурация готова к PostgreSQL в проде
