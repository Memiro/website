# 16 — Движок цены

**What to build:** Ядро расчёта: по размерам, выбранным атрибутам и тарифам получается цена. Полотно считается по площади, обработка кромки и контурная подсветка — по периметру, фронтальная — по площади, кнопка, подогрев и вырез — за штуку; коэффициент формы умножает стекло и кромку. Площадь берётся не меньше минимальной, итог не ниже минимальной суммы заказа и округляется вверх до 100 ₽. Витрины у этого тикета нет — результат виден в тестах.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Чистая функция «параметры конфигурации + тарифы → цена»; тарифы приходят аргументом, модели Django внутрь не импортируются
- [ ] Реализация подменяема: формулу можно заменить, не трогая тех, кто её зовёт
- [ ] Табличные тесты без базы: два зеркала одной площади и разного периметра дают разную цену
- [ ] Коэффициент формы умножает стекло и кромку и не трогает подсветку и штучные статьи
- [ ] Зеркало меньше минимальной площади считается по минимальной; итог поднимается до минимальной суммы заказа
- [ ] Округление вверх до 100 ₽
- [ ] Комбинированная подсветка равна сумме контурной и фронтальной; температура даёт надбавку только у значения «3 в 1»
- [ ] Не выбранная кнопка не оплачивается, даже когда в изделии есть подсветка и подогрев

## Notes

Формула и обоснование единиц — ADR-0007. Второй шов проекта по `spec.md`: «движок цены — чистая функция, табличные тесты». Тарифы аргументом — именно поэтому тикет не ждёт тикета 15.
