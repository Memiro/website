# Визуальный прогон витрины

Скрипты для проверки адаптива глазами и замерами. Живут в `.scratch/`, как и перенос данных: это инструмент разработки, а не продукт — в зависимости проекта playwright не вводится.

## Зачем

Проверки по токенам палитры не ловят целый класс дефектов: печатающиеся комментарии шаблонов, затёртые боковые поля, горизонтальное переполнение. Прогон 2026-08-21 нашёл пять таких (тикет 12).

## Как запустить

Браузера в системе нет, ставить его туда не нужно — headless Firefox уезжает в кэш пользователя:

```sh
uvx --from playwright playwright install firefox
```

Загрузка FFmpeg в конце падает — это нормально, он нужен только для записи видео.

Каталог показывает товары, только если они опубликованы, а после переноса (тикет 11) они черновики. Поэтому: копия базы → временная публикация → прогон → возврат копии.

```sh
cp db.sqlite3 /tmp/db.bak
uv run python .scratch/new-site/visual/publish.py     # временно публикует товары
uv run python manage.py runserver 127.0.0.1:8009 --noreload &
uv run --with playwright python .scratch/new-site/visual/shots.py /tmp/shots
uv run --with playwright python .scratch/new-site/visual/measure.py
uv run --with playwright python .scratch/new-site/visual/tiles.py /tmp/tiles
cp /tmp/db.bak db.sqlite3                             # вернуть черновики
```

`shots.py` снимает двенадцать адресов на трёх ширинах, `measure.py` ищет горизонтальное переполнение и потерянные боковые поля, `tiles.py` разбирает блок плиток главной (порядок, адреса, обложки — тикет 14).

## Чего не делать

- **`runserver --noreload` держит шаблоны в кэше.** После правки шаблона сервер надо перезапустить, иначе снимешь старую разметку.
- **Одних картинок мало.** `body { overflow-x: hidden }` прячет горизонтальную полосу прокрутки: страница шириной 2204px при экране 390 выглядит на снимке нормально, товары просто обрезаны за краем. Переполнение ловит `measure.py` — сравнивает `scrollWidth` с `innerWidth`.
- **Полностраничный снимок не догружает `loading="lazy"`** ниже сгиба. Для кадров с фотографиями прокручивай страницу перед снимком.
