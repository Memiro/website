## Problem Statement

Действующий сайт студии (memiro.ru) — WordPress с темой, экспортированной из Webflow. Владельцу сложно и дорого его развивать: тарифы калькулятора цен зашиты в 599 строк JavaScript внутри темы, контент управляется связкой платных плагинов (ACF Pro, Filter Everything Pro, Yoast Premium, WPForms), код страниц — монолитные PHP-файлы. Владелец хочет сайт, который быстро работает, отлично индексируется поисковиками, красиво выглядит и позволяет быстро вносить правки — при этом сам владелец пишет на Python и хочет управлять товарами через админ-панель без правок кода.

## Solution

Новый сайт с нуля: Django-монолит с серверным рендерингом страниц (нативное SEO), встроенной Django-админкой для управления контентом и типизированными JSON-эндпоинтами на django-modern-rest для интерактива (калькулятор, заказ, фильтры). Полный редизайн по taste-скиллам с сохранением wordmark «memiro»; порядок работы — сначала макеты, после утверждения — вёрстка, затем подключение данных. Разработка локально; продакшен позже на VPS Beget, старый сайт живёт до переключения DNS.

## Implementation Decisions

- **Архитектура**: Django-монолит. Страницы рендерятся сервером из шаблонов (SSR). Никакого отдельного JS-фронтенда и Node на сервере.
- **JSON-эндпоинты**: django-modern-rest (wemake-services) внутри того же проекта — для пересчёта цены калькулятором, отправки заказа и динамической фильтрации. Строгая валидация запросов/ответов, OpenAPI-схема.
- **Админка**: нативная Django admin. Управляет: товары, категории, тарифы/коэффициенты калькулятора, акции, отзывы, FAQ, журнал заказов. Тексты статических страниц — в коде, не в админке.
- **Движок расчёта цены** — отдельный модуль с чистым интерфейсом: (параметры запроса + тарифы из БД) → цена. Первая реализация переносит текущую логику старого сайта (м² × тариф × коэффициент по «комбинации» и подсветке); все числа — в БД, редактируются в админке. Новая логика будет спроектирована отдельно и вставится заменой реализации.
- **Заказы**: без личных кабинетов и без онлайн-оплаты. Корзина и избранное — на стороне браузера (localStorage); оформление — POST на эндпоинт, заказ сохраняется в БД и триггерит уведомление в Telegram.
- **Данные товаров**: модель полей — по текущим ACF-полям старого сайта (артикул, цена, описание, форма, рама, материал/цвет рамы, подсветка, расположение, наличие, комбинация, акция, популярное, фото, галерея). Миграция 88 товаров с фото — скриптом с прод-сервера (SSH-доступ настроен).
- **БД**: SQLite в разработке, PostgreSQL в продакшене.
- **Дизайн**: полный редизайн по taste-скиллам, wordmark «memiro» сохраняется. Процесс: макеты → утверждение владельцем → вёрстка → подключение данных. Скролл-анимации и микровзаимодействия обязательны, но без ущерба скорости.
- **SEO**: семантическая разметка, метатеги, schema.org, sitemap — с нуля; цель ~100 баллов PageSpeed/валидаторы.
- **Хостинг**: разработка локально; продакшен — VPS Beget (заказывается позже с разрешения владельца). Старый WP-сайт не трогаем до переключения DNS.

## Testing Decisions

- Хороший тест проверяет только внешнее поведение, видимое пользователю или клиенту API, — не внутренности реализации.
- **Основной шов — HTTP**: тестовый клиент Django запрашивает страницы и эндпоинты как браузер. Примеры: страница каталога содержит товары из БД; фильтр возвращает только подходящие товары; POST формы заказа создаёт запись в журнале и отправляет уведомление (Telegram — через подменённый транспорт); страницы отдают корректные метатеги.
- **Второй шов — движок расчёта цены**: чистая функция тестируется таблично (параметры + тарифы → ожидаемая цена), включая паритет с формулами старого сайта на контрольных примерах.
- Других швов нет. Вёрстка и дизайн проверяются владельцем по макетам; стандартная Django-админка отдельно не тестируется.
- Прецедентов тестов в репозитории нет — репозиторий новый; эти тесты станут прецедентом.

## Out of Scope

- Новая логика калькулятора (проектируется отдельной сессией; сейчас — перенос текущей с тарифами в админке)
- Переработка структуры каталога и набора фильтров (отдельная сессия; поля закладываются по текущим)
- Карта 301-редиректов со старых URL (составляется перед запуском)
- Финальный SEO-прогон на 100 баллов (перед запуском)
- Заказ и настройка VPS, деплой, переключение DNS
- Блог/новости, личные кабинеты, онлайн-оплата
