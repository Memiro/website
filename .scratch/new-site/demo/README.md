# Демонстрационные цены

`seed_pricing.py` заполняет **локальную** базу тем, чего ждёт владелец:
ставками в справочнике, параметрами расчёта, недостающей разметкой товаров
и предпосчитанными вариантами. Без них витрина молчит о цене (тикет 18) и
не показывает калькулятор (тикет 20) — смотреть не на что.

```sh
uv run python .scratch/new-site/demo/seed_pricing.py         # завести
uv run python .scratch/new-site/demo/seed_pricing.py --undo  # снять
```

Прогон отказывается работать там, где задан `POSTGRES_HOST`: выдуманная
ставка на боевой базе назвала бы покупателю неверную цену — ровно то, из-за
чего `remap.py` тарифы ставить и отказался.

## Что ставит прогон

| | |
|---|---|
| Тарифы | 35 значений справочника: полотно за м², рама и подсветка за погонный метр, кнопка/подогрев/крепление/вырез за штуку, форма — коэффициентом |
| Параметры расчёта | мин. площадь 0,25 м², мин. сумма 2 000 ₽, предел 2400×1500 мм |
| Разметка | 428 строк: заполняются только пробелы, значение выводится из названия и описания товара |
| Варианты | по три типовых размера на товар — 600×800, 800×1000, 1000×1400 |

Итог прогона: все 88 товаров получают цену (2 700–24 000 ₽) и калькулятор.

Повторный прогон ничего не удваивает. Отчёт ложится в `seeded.json` — по нему
`--undo` снимает ровно заведённое прогоном и возвращает прежние тарифы,
не трогая того, что вы завели руками.

## Чего прогон не делает

**Не угадывает того, чего не знает.** Вид подсветки берётся из описания
товара, где он назван словом, а тип полотна — из названия; всё остальное
получает умолчание («серебро», «с креплением», «нейтральная»). Это
годится, чтобы увидеть страницу с числами, и не годится ни для чего
больше: настоящую разметку ставит владелец (тикет 22, `owner-todo.md`).

**Не заводит сироту.** Температуры свечения не бывает у зеркала без
подсветки, кнопки — без подсветки и подогрева. Прогон пропустил 135 таких
строк. Проверка живёт в форме товара, а скрипт пишет мимо форм — о чём и
предупреждал тикет 15 («скрипту нужна своя проверка на выходе»); здесь она
своя, `Attribute.missing_parent_error`, то же правило, что и в админке.

## Ставки подсветки

Подсветка вся меряется погонным метром, с какой бы стороны полотна ни шла
лента, — разнятся у видов ставки, а не единица (владелец, 2026-08-24).
Комбинированная поэтому укладывается одной строкой справочника: её ставка
за метр — сумма контурной и фронтальной. Демо-числа: 2 500, 3 200 и 5 700 ₽
за погонный метр.
