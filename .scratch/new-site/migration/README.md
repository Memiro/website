# Перенос каталога со старого сайта (тикет 11)

Разовая операция, а не часть продукта: скрипты живут здесь, в
кодовую базу и зависимости проекта не попадают.

Старый сайт — WordPress на `podobnmi@podobnmi.beget.tech`,
`~/memiro.ru/public_html`, wp-cli на месте. Товары там лежали типом
записи `catalog` (не `mirrors` — так называется только URL-префикс),
характеристики — полями ACF, категорий и таксономий не было вовсе.

## Порядок

1. **Выгрузка** (только чтение, на сервере):

   ```sh
   scp export_catalog.php  podobnmi@podobnmi.beget.tech:~/memiro_export.php
   scp export_media.php    podobnmi@podobnmi.beget.tech:~/memiro_media.php
   ssh podobnmi@podobnmi.beget.tech \
     'cd ~/memiro.ru/public_html && wp eval-file ~/memiro_export.php > ~/memiro_catalog.json'
   ```

   `export_acf.php` и `export_filters.php` — вспомогательные: из них
   взяты подписи значений атрибутов, чтобы не выдумывать свои.

2. **Фотографии**: `export_media.php` отдаёт `media.json` со списком
   вложений; нужные файлы (оригинал + размер WP `medium_large`)
   упаковываются `tar -T` и распаковываются в `uploads/`. Каталог
   `uploads/` в git не идёт — 50 МБ, качается заново.

3. **Импорт** (из корня репозитория):

   ```sh
   uv run python .scratch/new-site/migration/migrate.py --reset
   uv run python manage.py import_legacy_urls .scratch/new-site/migration/redirects.json
   ```

   `--reset` убирает демо-категории и демо-товары, которыми витрина
   жила до переноса (список слагов в скрипте явный — настоящую
   категорию владельца прогон не тронет). Скрипт идемпотентен:
   повторный прогон обновляет те же товары по слагу и переписывает
   их фото, не плодя ни записей, ни файлов-сирот.

## Карта переезда

`redirects.json` — 113 правил на 301 и 19 на 410:

- 88 карточек товара `/mirrors/<slug>/` → `/catalog/zerkala/<slug>/`;
- 23 прежних слага из `_wp_old_slug` (у 23 зеркал слаг когда-то был
  кириллическим, WordPress сам отдавал их 301-м) — в карту идут
  раскодированными, потому что `request.path` в Django раскодирован;
- 4 статические страницы: `/privacy-policy/`, `/about-us/`,
  `/delivery-payment-and-services/`, `/contacts/`. `/` и `/catalog/`
  в карту не попадают: адрес не сменился, а правило на самого себя
  стало бы петлёй;
- на 410 уходят тестовая страница, единственная статья старого блога
  и 17 страниц вопросов `/faq/<slug>/` — на новом сайте FAQ это блок
  главной, отдельных адресов у вопросов нет.

## Решения переноса

- **Одна категория «Зеркала»** (`/catalog/zerkala/`). Категория новой
  модели — тип товара (`CONTEXT.md`: зеркала, душевые перегородки), а
  старые поля `форма`/`рама`/`подсветка` — это атрибуты: одно зеркало
  разом и круглое, и с подсветкой, и в раме, категорией такое не
  выразить. Плитки «Зеркала с подсветкой», «Круглые зеркала» из макета
  v2 — это посадочные (ADR-0003), их заводит владелец.
- **Шесть атрибутов** — расположение, форма, подсветка, рама, цвет
  рамы, материал рамы. В справочник заведены только значения,
  встретившиеся в данных: словарь ACF знал ещё «Дерево», но ни одно из
  88 зеркал его не носит.
- **`nalichie` (в наличии / нет) отброшено** — наличия в новой модели
  нет, всё под заказ.
- **`details` отброшено**: у 23 товаров там стоит «Зеркала напольные»
  при `location = nastennoe` — поле противоречит собственному
  `Расположению` и выглядит следом пакетной правки. Верим `location`.
- **`combinaciya` / `combinaciya_test` отброшены** — группировка
  вариантов старого сайта, в новой модели такого понятия нет.
- **Дата создания** перенесена из `post_date`: иначе сортировка
  «новинки» показывала бы порядок импорта.
- **Все товары — черновики.** Публикует владелец после вычитки.

## Что осталось владельцу

- `price-missing.md` — 48 товаров, у которых на старом сайте стояло
  «Цена по запросу». В новой модели цена обязательна, поэтому стоит
  заглушка 1 ₽; товар остаётся черновиком, на витрину заглушка не
  выходит.
- Вычитка и публикация остальных 40.

## Что не переносилось

Тексты 17 вопросов FAQ старого сайта (тип записи `faq`) — тикет 11 про
товары; наполнить ими `FaqEntry` — отдельная работа. Их адреса при
этом в карте переезда есть, на 410.
