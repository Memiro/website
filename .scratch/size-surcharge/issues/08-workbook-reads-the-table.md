# 08 — Книга расчёта берёт наценку из базы

**What to build:** Генератор книги (`catalog/workbook.py`) заполняет колонку
«умножается наценкой за размер» из поля значения и лист «Наценка за размер» —
из таблицы ступеней, вместо заготовки.

**Why:** Книга существует затем, чтобы владелец щупал цену до витрины, и
расхождение книги с сайтом считается дефектом. Пока признака и таблицы не было
в базе, книга держала их своей константой и пустой колонкой; оставшись, они
однажды разойдутся с админкой.

**Blocked by:** 01, 02.

**Status:** ready-for-agent

- [ ] Колонка признака в справочнике книги заполняется из поля значения
- [ ] Лист ступеней собирается из таблицы; константа-заготовка удаляется
- [ ] Пустая таблица даёт пустой лист, и формулы книги дают коэффициент 1
- [ ] Лист «Сверка» продолжает совпадать с движком — теперь и с наценкой
- [ ] Тесты в `tests/test_workbook.py`
