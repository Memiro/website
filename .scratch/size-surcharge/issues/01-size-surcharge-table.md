# 01 — Таблица ступеней «Наценка за размер»

**What to build:** Модель ступени наценки и экран в админке. Строка — порог по
наибольшей стороне изделия (мм) и коэффициент. Таблица одна на сайт, соседка
«Параметров расчёта».

**Why:** Крупное зеркало сложнее в работе, и выразить это данными сегодня
нечем: все коэффициенты расчёта приходят из значения атрибута, а значение
выбирают — размер же вводят миллиметрами (ADR-0010).

**Blocked by:** None.

**Status:** ready-for-agent

- [ ] Модель ступени: порог, мм (целое) и коэффициент; порядок — по порогу
- [ ] Одна таблица на сайт, не на категорию: пороги листа общие, а второе
      место для наценки однажды разошлось бы с первым
- [ ] Экран в админке рядом с «Параметрами расчёта», по-русски
- [ ] Два порога с одним значением не заводятся: ступень при этом одна, а
      какая именно — вопрос без ответа
- [ ] Коэффициент положительный; ноль означал бы бесплатное изделие
- [ ] Пустая таблица — валидное состояние, означает «наценки нет». Строка с
      коэффициентом 1,0 для выключения не нужна и заводиться не должна
- [ ] Тесты: заведение, порядок ступеней, отказ от дубля порога
