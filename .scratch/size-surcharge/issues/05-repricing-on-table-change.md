# 05 — Правка ступеней пересчитывает витрину

**What to build:** Заведение, правка и удаление ступени пересчитывают цены всех
вариантов и «цену от» товаров.

каталог показывал бы вчерашние числа, а расхождение обнаружилось бы по жалобе.
