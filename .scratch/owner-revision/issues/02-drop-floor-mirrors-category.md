# 02 — Удалить категорию «Напольные зеркала»

**What to build:** Категория «Напольные зеркала» удаляется с сайта вместе с
товарами, которые в ней заведены.

**Why:** Владелец: «у нас не будет категории напольные зеркала, потому что таких
зеркал нет». Товары старого сайта из этой категории будут разложены по другим
категориям при наполнении, вручную и не сейчас.

**Blocked by:** None.

**Status:** ready-for-human

- [ ] Показать владельцу список товаров, которые уйдут вместе с категорией,
      и получить его «да» до удаления
- [ ] Категория и её товары удалены
- [ ] Проверено, что на неё не ссылаются посадочные и плитки главной;
      если ссылаются — они удаляются вместе с ней
- [ ] Витрина не отдаёт 500 нигде, где категория упоминалась

**Редирект не нужен:** сайт не запущен, адрес никем не виден (решение владельца,
круг 3). Карты переезда со старого сайта это не касается.
