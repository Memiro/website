# 04 — Вырезать избранное

**What to build:** Избранного на сайте не остаётся ни в каком виде.

**Why:** Владелец: «не должно быть такой функции как избранное на сайте».
Функция не оправдала себя: витрина на 88 зеркал под заказ — не тот случай,
где покупатель ведёт списки. Каждая лишняя иконка на плитке ломает строку с
ценой (см. issue 10).

**Blocked by:** None.

**Status:** ready-for-agent

- [ ] Сердечки убраны с плитки каталога (`templates/catalog/_card.html`) и
      со страницы товара (`templates/catalog/product.html`)
- [ ] Шаблон `templates/inquiries/favorites.html` удалён
- [ ] Маршрут и представление избранного удалены (`inquiries/urls.py`,
      `inquiries/views.py`)
- [ ] Эндпоинт избранного удалён (`inquiries/api.py`), вместе с ним — его
      идентификаторы в `api/ids.py`
- [ ] Ветка избранного удалена из `static/js/shop.js`, включая построение
      карточки `favoriteCard` и хранилище в браузере
- [ ] Ссылка и счётчик избранного убраны из `templates/base.html`
- [ ] Мета избранного убрана из `seo/meta.py` и `seo/views.py`
- [ ] Стили избранного убраны из `static/css/site.css`
- [ ] Адрес `/favorites/` отдаёт 404 — редиректа нет, сайт не запущен
- [ ] Тесты избранного удалены; остальные зелёные

**Понятия «Избранное» в CONTEXT.md нет** — глоссарий правки не требует.
