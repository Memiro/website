# 04 — Вырезать избранное

**What to build:** Избранного на сайте не остаётся ни в каком виде.

**Why:** Владелец: «не должно быть такой функции как избранное на сайте».
Функция не оправдала себя: витрина на 88 зеркал под заказ — не тот случай,
где покупатель ведёт списки. Каждая лишняя иконка на плитке ломает строку с
ценой (см. issue 10).

**Blocked by:** None.

**Status:** ready-for-human

- [x] Сердечки убраны с плитки каталога (`templates/catalog/_card.html`) и
      со страницы товара (`templates/catalog/product.html`)
- [x] Шаблон `templates/inquiries/favorites.html` удалён
- [x] Маршрут и представление избранного удалены (`inquiries/urls.py`,
      `inquiries/views.py`)
- [x] Эндпоинт избранного удалён (`inquiries/api.py`), вместе с ним — его
      идентификаторы в `api/ids.py`
- [x] Ветка избранного удалена из `static/js/shop.js`, включая построение
      карточки `favoriteCard` и хранилище в браузере
- [x] Ссылка и счётчик избранного убраны из `templates/base.html`
- [x] Мета избранного убрана из `seo/meta.py` и `seo/views.py`
- [x] Стили избранного убраны из `static/css/site.css`
- [x] Адрес `/favorites/` отдаёт 404 — редиректа нет, сайт не запущен
- [x] Тесты избранного удалены; остальные зелёные

**Понятия «Избранное» в CONTEXT.md нет** — глоссарий правки не требует.

## Comments

**2026-08-24, агент.** Избранное вырезано. Тесты зелёные (380), `just lint`,
`just static` и `pre-commit` чистые.

Два пункта чек-листа опирались на неверную посылку, и сделано по ним не то,
что написано:

- «Эндпоинт избранного удалён (`inquiries/api.py`)» — отдельного эндпоинта
  избранного никогда не было. `GET /api/products?ids=…` обслуживал обе
  подборки, и корзине он нужен по-прежнему; удалить его значило бы сломать
  корзину. Правлены только докстринги, которые называли избранное.
- «вместе с ним — его идентификаторы в `api/ids.py`» — `IDS_PATTERN`,
  `MAX_IDS_LENGTH` и `parse_ids` тоже общие: тем же разбором пользуется
  расчёт. Правлен только комментарий модуля.

Сверх чек-листа:

- Удалён `templates/icons/heart.svg` — после снятия сердечек иконку никто
  не включает.
- В `ADR-0005` дописано «Уточнение при реализации (тикет 04)»: решение
  «подборки на клиенте» в силе, но сузилось до одной подборки, а текст ADR
  описывал `/favorites/` как действующий адрес.
- В `shop.js` вид подборки (`kind`) оставлен параметром: он приходит из
  разметки, автотестов у витринного JS нет, а тикет 13 эту корзину всё
  равно переделывает в заявку. Причина записана комментарием в шапке файла,
  чтобы следующий читатель не счёл это заделом на будущее.

Не тронуто намеренно: макеты `design/mockups/*.html` и `design/heroes/` ещё
рисуют «Избранное» — это замороженный слепок хендофа (ADR-0004), а не
витрина. Стереть в чужих браузерах ключ `memiro:favorites` из `localStorage`
не пытались: сайт не запущен, класть в него было некому.
