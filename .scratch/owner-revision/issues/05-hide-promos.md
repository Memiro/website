# 05 — Убрать акции с витрины

**What to build:** Блок акций уходит с главной и бейдж «Акция» — с плиток.
Модель и флаг остаются в админке нетронутыми.

**Why:** Владелец: «акции пока убираем, продумаем позже и добавим». Удалять
модель ради временного скрытия — значит писать её заново через месяц. К моменту
возврата акции переделываются: вместо «специальных цен» блок будет называть
размер скидки в процентах (пункт 2 списка, отложен вместе с акциями).

**Blocked by:** None.

**Status:** ready-for-human

- [x] Блок акций убран с главной (`templates/home.html`)
- [x] Бейдж «Акция» убран с плитки (`templates/catalog/_card.html`) и со
      страницы товара
- [x] Выборка акционных товаров убрана из `views.py`
- [x] Модель `content.Promo`, флаг `Product.is_promo` и их разделы админки
      остаются на месте — миграций нет
- [x] Тесты главной не ждут блока акций

**CONTEXT.md:** термин «Акция» остаётся, но перестаёт описывать блок на главной.
Определение поправить: акция публикуется в админке и на витрине сейчас не
показывается.
