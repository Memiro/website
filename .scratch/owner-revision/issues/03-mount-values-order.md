# 03 — Порядок значений атрибута «Крепление»

**What to build:** Значения «Крепления» выстраиваются в осмысленном порядке:
с креплением → без крепления → на ножке.

**Why:** Владелец: «порядок в админке — с креплением, без крепления, на ножке».
Разработки здесь нет: поле `AttributeValue.order` уже существует, и сортировка
уже идёт `("order", "value")`. Если порядок сейчас алфавитный — значит у всех
значений стоит `0`, и это заполнение, а не баг.

**Blocked by:** None.

**Status:** ready-for-human

- [ ] Владелец проставляет «порядок» у значений «Крепления» в админке
- [ ] Если после заполнения порядок на витрине всё равно не тот — это баг,
      и тикет возвращается агенту с примером

**Проверить заодно:** те же нули наверняка стоят и у других справочников —
подсветка, форма, тип полотна. Владельцу стоит пройтись по ним разом.
