# Area

## Назначение

Площадь изделия в квадратных метрах — расход всего, что режется из листа:
полотна и обработки кромки. Получается только из [`Dimensions`](dimensions.md).

В коде — `entities/common/measure.py`.

## Состав

| Поле | Тип | Смысл |
|---|---|---|
| `value` | `Decimal` | Квадратные метры |

## Business Rules

1. `value` неотрицательна; нарушение — `NegativeMeasureError`.
2. Единственный законный источник — `Dimensions.area()`. Собранная из числа
   руками площадь — вторая правда о размере, и домен её не предлагает.
3. Величина дробная и полная: округления до квадратного метра нет. Маленькое
   зеркало иначе стоило бы как большое.
4. `at_least(minimum: Area) -> Area` поднимает площадь до минимальной площади
   расчёта из [`PricingSettings`](../entities/pricing-settings.md): маленькое
   зеркало считается по ней, потому что раскрой листа дешевле от этого не
   становится. Правило про то, откуда берётся `minimum`, живёт на странице
   параметров расчёта — здесь только сама операция.

## Где используется

Доменный сервис `pricing_service.price_product` — для значений с единицей
расхода `SQUARE_METER` (см. [`Rate`](rate.md)).
