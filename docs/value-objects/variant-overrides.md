# VariantOverrides

## Назначение

Неизменяемый набор отличий предпосчитанного варианта от деклараций товара.
Коллекция копирует принятые строки: вызывающий не может после команды изменить
конфигурацию ребёнка в обход `Product` и рассинхронизировать fingerprint.

В коде — `entities/catalog/product/entity.py`.

## Состав

| Элемент | Тип | Смысл |
|---|---|---|
| override | `DeclaredValue` | Значение одного атрибута, которым вариант отличается от товара |

## Business Rules

1. Один атрибут встречается не больше одного раза — иначе
   `InvalidVariantConfigurationError`.
2. Каждая строка содержит либо `value_id`, либо `quantity`; незавершённая
   декларация вариантом быть не может — иначе
   `InvalidVariantConfigurationError`.
3. Входные `DeclaredValue` копируются при создании, а наружу вариант также
   отдаёт копии. Состояние ребёнка меняется только командами агрегата.
4. Порядок элементов не участвует в тождестве варианта и перед сохранением
   канонизируется по `attribute_id`.

## Где используется

`VariantData` и `Variant` внутри [`Product`](../entities/product.md), а также
JSONB-тип адаптера вариантов.
