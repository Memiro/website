# Perimeter

## Назначение

Периметр изделия в погонных метрах — расход всего, что идёт по краю: контурной
ленты, алюминиевого профиля, багета. Получается только из
[`Dimensions`](dimensions.md).

В коде — `entities/common/measure.py`.

## Состав

| Поле | Тип | Смысл |
|---|---|---|
| `value` | `Decimal` | Погонные метры |

## Business Rules

1. `value` неотрицателен; нарушение — `NegativeMeasureError`.
2. Единственный законный источник — `Dimensions.perimeter()`, то есть
   2 × (ширина + высота).
3. Величина дробная и полная, без округления до метра.
4. Периметр — причина, по которой неменяемый атрибут всё равно участвует в
   расчёте: ленту и профиль покупатель не выбирает, но их метраж зависит от
   размеров, которые он вводит. Правило о меняемости живёт на странице
   [`Attribute`](../entities/attribute.md); здесь — то, откуда берётся его
   стоимость.
5. Минимальной границы у периметра нет: минимум расчёта задан площадью
   (см. [`Area`](area.md)), и второго минимума домен не заводит.

## Где используется

Доменный сервис `pricing_service.price_product` — для значений с единицей
расхода `LINEAR_METER` (см. [`Rate`](rate.md)).
