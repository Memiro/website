# Атрибуты товара — справочники в админке, не поля в коде

Ассортимент типов товаров растёт (зеркала, затем душевые перегородки, дальше неизвестно). Характеристики товара сделаны справочником «атрибутов» с привязкой к категории (EAV-лайт, простые типы: выбор из списка, да/нет, число); фильтры каталога строятся из них автоматически. Владелец заводит новую категорию без разработчика.

Отвергнутая альтернатива — жёсткие поля модели на категорию: проще и быстрее в запросах, но каждая новая категория превращается в задачу разработчику и миграцию. Общие для всех товаров поля (название, цена, фото, описание) остаются обычными колонками — в EAV уходят только фильтруемые характеристики.
