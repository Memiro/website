# Django-монолит с серверными шаблонами

Сайту нужны скорость и максимальный SEO-балл при маленькой команде. Выбран Django-монолит с SSR-шаблонами: HTML рендерится сервером и индексируется без JS-рендера, JSON-эндпоинты (django-modern-rest) — только для точечной интерактивности (калькулятор, «показать ещё»). SPA/фронтенд-фреймворк отвергнуты: для витрины с ~100–300 товарами они добавляют стоимость и риски SEO, не давая ощутимой пользы.
