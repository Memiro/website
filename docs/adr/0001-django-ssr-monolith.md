# Django-монолит с серверными шаблонами

**Заменён (2026-08-26).** Сайт переписывается с нуля до запуска: бэкенд —
FastAPI + async SQLAlchemy по agent-coding-instruction (дистилляция — в
`AGENTS.md`), витрина — Astro SSR с островами Vue (ADR-0013), Django остаётся
только админкой — второй презентацией того же контекста (ADR-0012). Решения
ADR-0002…0010 переезжают без ревизии; ADR-0011 — с уточнением: варианты
правятся поштучными командами агрегата, а живую цену собранного показывает
та же точка, что её запишет.

Сайту нужны скорость и максимальный SEO-балл при маленькой команде. Выбран Django-монолит с SSR-шаблонами: HTML рендерится сервером и индексируется без JS-рендера, JSON-эндпоинты (django-modern-rest) — только для точечной интерактивности (калькулятор, «показать ещё»). SPA/фронтенд-фреймворк отвергнуты: для витрины с ~100–300 товарами они добавляют стоимость и риски SEO, не давая ощутимой пользы.
