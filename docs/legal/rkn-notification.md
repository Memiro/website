# Уведомление РКН об обработке персональных данных

Что подавать в кабинете **pd.rkn.gov.ru** и откуда взяты ответы. Подача
бесплатная, подаёт владелец (оператор), агент за него этого сделать не может.
Правовая база и штрафы — `docs/research/ru-legal-requirements-2025-2026.md`,
раздел 1.

**Почему это блокирует Метрику.** По ст. 22 152-ФЗ уведомление подаётся **до**
начала обработки; с 30.05.2025 исключение «только клиентские контакты» снято.
Заявки сайт собирает уже сейчас, то есть уведомление просрочено независимо от
аналитики. Счётчик Метрики добавляет к составу cookie-идентификаторы и IP и
делает обработку публично заметной. Поэтому `METRIKA_ID` на проде остаётся
пустым, пока уведомление не подано (ADR-0006).

## Что отвечать в форме

Поля с `<…>` заполняет владелец — в репозитории этих сведений нет.

| Поле формы | Ответ |
|---|---|
| Оператор | `<наименование или ФИО ИП>`, ОГРН(ИП) `<…>`, ИНН `<…>` — те же реквизиты, что печатаются в футере и в политике |
| Адрес места нахождения | `<юридический адрес>` (адрес шоурума к реквизитам не относится) |
| Ответственный за организацию обработки | `<ФИО, телефон, email>` — назначается приказом |
| Цель обработки | обработка заявок на изготовление зеркал и обратная связь с клиентом; сбор обезличенной статистики посещений сайта |
| Правовое основание | ст. 6 ч. 1 п. 1 и ст. 9 152-ФЗ — согласие субъекта; договорные отношения по заказу |
| Категории субъектов | посетители сайта memiro.ru, оставившие заявку; посетители сайта (cookie-идентификаторы) |
| Перечень ПД | имя; номер телефона; адрес электронной почты (необязательный); содержание заявки — состав заказа и личное пожелание; дата и редакция данного согласия; cookie-идентификатор, IP-адрес, характеристики устройства и браузера, просмотренные страницы (Яндекс.Метрика, только после согласия) |
| Способы обработки | смешанная, с передачей по внутренней сети и по сети «Интернет» |
| Действия с ПД | сбор, запись, систематизация, накопление, хранение, уточнение, извлечение, использование, удаление, уничтожение |
| Обработка без средств автоматизации | нет |
| Трансграничная передача | нет — все ресурсы размещены в РФ |
| Поручение обработки третьим лицам | хостинг VPS `<Beget, реквизиты по договору>`; ООО «Яндекс» — Яндекс.Метрика и почтовый сервис для уведомлений менеджера |
| Сроки обработки / условие прекращения | до отзыва согласия либо до истечения срока в п. 5 политики |
| Меры по ст. 18.1 и 19 | опубликованная политика, назначенный ответственный, TLS, ограничение доступа к админке, парольная политика |
| Дата начала обработки | `<фактическая дата запуска формы заявки>` |

Перечень ПД и сроки должны совпадать с текстом политики
(`frontend/app/pages/privacy/index.astro`, разделы 2, 5 и 7). Правка политики и
`consent_version` идут одним коммитом — расхождение обесценивает доказательство.

## После подачи

1. Дождаться появления оператора в реестре РКН.
2. Выставить `METRIKA_ID` в `.env` на сервере и поднять контур заново.
3. Проверить гейт на проде:
   `curl -s https://memiro.ru/ | grep -c mc.yandex.ru` → `0`,
   с `-b cookie_consent=yes` — не ноль (счётчик и `noscript`-пиксель).
4. Внутренние документы оператора (приказ о назначении ответственного,
   перечень ПД, модель угроз) — минимальный комплект, который РКН запрашивает
   при проверке; его у студии пока нет.
