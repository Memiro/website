# Посадочная страница (`Landing`)

Индексируемая страница витрины: одна категория, суженная значениями атрибутов,
со своим адресом в корне сайта, заголовком и SEO-текстом владельца (ADR-0003).
Корень агрегата; условия сужения — его дети, и набор заменяется целиком
командой `narrow_by`, а не правится построчно.

## Поля

| Поле | Тип | Смысл |
|---|---|---|
| `id` | `LandingId` | Идентификатор (UUID) |
| `category_id` | `CategoryId` | Категория, которую страница сужает |
| `slug` | `str` | Адрес в корне сайта |
| `title` | `str` | Мета-заголовок |
| `heading` | `str` | Заголовок страницы и подпись плитки |
| `description` | `str` | Мета-описание |
| `text` | `str` | Текст владельца; витрина печатает первый абзац лидом, остальное не показывает |
| `is_published` | `bool` | Видна ли на витрине |
| `sort_order` | `int` | Порядок среди плиток, поле владельца |
| `conditions` | `tuple[LandingCondition, ...]` | Значения сужения, дети агрегата |
| `created_at` | `datetime` | Когда страница заведена |
| `updated_at` | `datetime` | Когда её меняли в последний раз |

`LandingCondition` — пара «атрибут, значение». Своего идентификатора у неё нет:
набор заменяется целиком, и различает строки само значение.

## Правила

1. Страница сужает ровно одну категорию: категорию правка не меняет — от
   переезда у страницы не осталось бы ни одного своего условия.
2. Сужение непустое: страница без условий — это категория под вторым адресом.
3. Сужают не больше `MAX_LANDING_ATTRIBUTES` = 2 атрибутов; значений у одного
   атрибута сколько угодно — между собой они по ИЛИ, тем же правилом, что и в
   сайдбаре (ADR-0003, уточнение подтверждено владельцем).
4. Каждое значение названо один раз.
5. Сужать можно только фильтруемым `SELECT`-атрибутом своей категории: у
   посадочной нет второй реализации сужения, и условие, которое сайдбар
   выбрасывает, оставило бы страницу с полной категорией под сужающим
   заголовком. Проверяется службой `ensure_the_narrowing_is_buildable`:
   агрегату для этого нужен справочник, которого он не видит (§6.3c).
6. Перечислить все значения атрибута нельзя — это дубль категории под своим
   адресом.
7. Пустой адрес выводится из заголовка транслитерацией; выводить нечего —
   `INVALID_LANDING_SLUG`. Уникальность адреса — факт транзакции, а не
   агрегата: её держит база и проверяет интерактор (`LANDING_SLUG_TAKEN`).
8. Снятая с публикации страница пропадает и с адреса, и из плиток, но адрес
   остаётся занятым: это способ убрать страницу, не отдав её адрес.
