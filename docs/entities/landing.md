# Landing — посадочная

## Назначение

Вручную заведённая в админке индексируемая ЧПУ-страница на категорию плюс
одно-два значения атрибутов («зеркала с подсветкой»), со своими title/h1 и
уникальным текстом. Единственный индексируемый вид фильтрации (ADR-0003).

_Avoid_: SEO-страница, тег, автофильтр.

Корень агрегата; внутри — условия `LandingCondition`. В коде —
`entities/content/landing.py`.

## Атрибуты

| Поле | Тип | Смысл |
|---|---|---|
| `id` | `LandingId` | Идентификатор (UUID) |
| `category_id` | `CategoryId` | Категория, которую посадочная сужает |
| `slug` | `str` | Адрес в публичном URL |
| `title` | `str` | Заголовок вкладки |
| `h1` | `str` | Заголовок страницы |
| `text` | `str` | Уникальный текст |
| `cover_image_key` | `str \| None` | Обложка плитки на главной |
| `is_published` | `bool` | Видна на витрине и индексируется |
| `sort_order` | `int` | Порядок плиток, поле владельца |
| `conditions` | `list[LandingCondition]` | Условия сужения |
| `created_at` | `datetime` | |
| `updated_at` | `datetime` | |

### LandingCondition — условие посадочной

Значение атрибута, которым посадочная сужает свою категорию. Условие заводит
владелец, и страница с ним индексируется — этим оно и отличается от фильтра,
который выбирает посетитель и который от индексации закрыт.

_Avoid_: фильтр посадочной.

| Поле | Тип | Смысл |
|---|---|---|
| `attribute_id` | `AttributeId` | Сужающий атрибут |
| `value_id` | `AttributeValueId` | Значение этого атрибута |

## Business Rules

1. Значения одного атрибута объединяются по ИЛИ, разные атрибуты — по И: тем же
   правилом, что и фильтр каталога. «Зеркала в раме» это и алюминий, и багет,
   «с подсветкой» — контурная, фронтальная и комбинированная разом.
2. Предел `MAX_LANDING_ATTRIBUTES` (одно-два) лежит на числе **сужающих
   атрибутов**, а не на числе строк: несколько значений одного атрибута —
   по-прежнему один вопрос к товару, и хвоста фильтра они не удлиняют.
   Нарушение — `TooManyLandingAttributesError`.
3. Перечисленные все значения атрибута сужением быть перестают — такая страница
   дубль категории, и домен её не принимает: `LandingDoesNotNarrowError`.
4. Посадочная заводится только по фильтруемому атрибуту (`is_filterable`):
   индексируемая страница с сужением, которого в сайдбаре нет, — вторая правда о
   каталоге. Нарушение — `AttributeNotFilterableError`.
5. Атрибут и значение принадлежат категории посадочной; чужие —
   `ConditionOutsideCategoryError`.
6. `slug` уникален по сайту: на нём стоит публичный адрес — `LandingSlugTakenError`.
7. Условия меняются целиком одной командой корня (`replace_conditions`) — одна
   доменная транзакция на корень и его инлайн-формсет (решение 60).
8. Плитка на главной — картиночный вход в каталог: адрес, подпись и обложка.
   Плитки набираются из посадочных; категория плиткой не становится — она тип
   товара. Пока `cover_image_key` пуст, плитка берёт фото первого товара.
9. Фильтры каталога от индексации закрыты; посадочная — исключение, и потому она
   заводится руками, а не автоматом по всякому сочетанию значений.

## Связи

```
Category
  └── Landing                    (по category_id)
        └── LandingCondition*    (attribute_id → Attribute, value_id → AttributeValue)
              ├── одного атрибута — по ИЛИ
              └── разных атрибутов — по И, не более MAX_LANDING_ATTRIBUTES
```
