# Удаление посадочной страницы

**Актор:** владелец, установленный Django-презентацией.

Владелец убирает страницу, которая больше не нужна. Условия сужения уходят с
ней: они её дети, а не отдельная сущность.

## Input

| Поле | Тип | Смысл |
|---|---|---|
| `landing_id` | `UUID` | Удаляемая посадочная |

## Output

Нет.

## Business Rules

1. Посадочная существует — иначе `LANDING_NOT_FOUND` (404).
2. Ничто не держит посадочную: на неё никто не ссылается, и удаление всегда
   проходит. Обратное — снять с публикации: адрес тогда остаётся занятым.
3. Условия удаляются вместе с ней одной транзакцией.

## Errors

| Код | HTTP | Когда |
|---|---|---|
| `LANDING_NOT_FOUND` | 404 | Посадочной с таким идентификатором нет |
| `CONCURRENT_CHANGE` | 429 | Строку правят в другом окне |
