# Заведение посадочной страницы

**Актор:** владелец, установленный Django-презентацией.

Владелец заводит индексируемую страницу под конкретный спрос: категория,
суженная значениями атрибутов, со своим адресом, заголовком и текстом
(ADR-0003). Интерактор зовёт карточка посадочной в админке через мост.

Читают заведённое [«Посадочная страница»](../browse_catalog/read-landing.md)
и [«Список посадочных»](../browse_catalog/list-landings.md).

## Input

`CreateLandingForm`

| Поле | Тип | Смысл |
|---|---|---|
| `category_id` | `UUID` | Категория, которую страница сужает |
| `slug` | `str` | Адрес в корне сайта; пустой транслитерируется из заголовка |
| `title` | `str` | Мета-заголовок |
| `heading` | `str` | Заголовок страницы и подпись плитки |
| `description` | `str` | Мета-описание |
| `text` | `str` | SEO-текст владельца; пустой не печатается |
| `is_published` | `bool` | Видна ли на витрине |
| `sort_order` | `int` | Место среди плиток |
| `conditions` | `list[UUID]` | Значения атрибутов, которыми сужается выдача |

## Output

`CreatedLanding`

| Поле | Тип | Смысл |
|---|---|---|
| `id` | `UUID` | Идентификатор новой посадочной |

## Business Rules

Правила идут в порядке, в котором их проверяет интерактор.

1. Заголовок непустой и не длиннее `MAX_NAME_LENGTH`, тексты не длиннее своих
   границ, адрес — пустой или строчная латиница с цифрами через дефис — иначе
   `VALIDATION_ERROR` (422).
2. Категория существует — иначе `CATEGORY_NOT_FOUND` (404).
3. Сужение непустое: страница без условий — это категория под вторым адресом.
   Отказ `INVALID_LANDING_NARROWING` (400).
4. Каждое значение названо один раз: карточка отправляет набор, а не список.
   Повтор — `INVALID_LANDING_NARROWING` (400).
5. Сужают не больше двух атрибутов (`MAX_LANDING_ATTRIBUTES`); значений у
   одного атрибута сколько угодно — между собой они по ИЛИ, тем же правилом,
   что и в сайдбаре. Больше — `INVALID_LANDING_NARROWING` (400).
6. Каждое значение принадлежит атрибуту сужаемой категории, атрибут —
   `SELECT` и строит фильтр (`is_filterable`). Иначе сайдбар это условие
   выбросил бы, а страница показала бы всю категорию:
   `INVALID_LANDING_NARROWING` (400).
7. Перечислить все значения атрибута нельзя: это дубль категории под своим
   адресом — `INVALID_LANDING_NARROWING` (400).
8. Пустой адрес выводится из заголовка транслитерацией; если выводить нечего —
   `INVALID_LANDING_SLUG` (400).
9. Адрес свободен среди посадочных — иначе `LANDING_SLUG_TAKEN` (409).
   Уникальность держит база, проигранная гонка — `CONCURRENT_CHANGE` (429).
   Адрес занятой страницы сайта посадочная не отбирает: её маршрут
   разбирается последним (ADR-0003), и такая страница просто не откроется.
10. `created_at` и `updated_at` берутся одним `clock.now()`: страница рождается
    со своим сужением, а не досуживается вторым движением.

## Errors

| Код | HTTP | Когда |
|---|---|---|
| `VALIDATION_ERROR` | 422 | Форма не прошла границы ввода |
| `CATEGORY_NOT_FOUND` | 404 | Категории нет |
| `INVALID_LANDING_SLUG` | 400 | Из заголовка не выводится ни одного символа адреса |
| `INVALID_LANDING_NARROWING` | 400 | Сужение пустое, шире двух атрибутов, чужое или равно всей категории |
| `LANDING_SLUG_TAKEN` | 409 | Адрес занят другой посадочной |
| `CONCURRENT_CHANGE` | 429 | Адрес занял конкурент между проверкой и записью |
