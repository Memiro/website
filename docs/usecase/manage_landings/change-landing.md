# Правка посадочной страницы

**Актор:** владелец, установленный Django-презентацией.

Владелец правит заведённую страницу: тексты, адрес, публикацию, порядок и
сужение. Категория не меняется — сужение принадлежит своей категории, и
переезд означал бы страницу, у которой не осталось ни одного своего условия;
такую заводят заново.

## Input

`ChangeLandingForm` — те же поля, что у [заведения](create-landing.md), кроме
`category_id`, плюс идентификатор правимой страницы отдельным аргументом.

## Output

Нет.

## Business Rules

1. Границы ввода — как при заведении, иначе `VALIDATION_ERROR` (422).
2. Посадочная существует — иначе `LANDING_NOT_FOUND` (404). Строка правится
   под своей блокировкой: параллельная правка той же страницы ждёт, а
   отказанная блокировка возвращается `CONCURRENT_CHANGE` (429).
3. Адрес свободен или принадлежит этой же странице — иначе
   `LANDING_SLUG_TAKEN` (409).
4. Сужение проверяется правилами 3–7 [заведения](create-landing.md) — непустое,
   без повторов, не шире двух атрибутов, только фильтруемыми `SELECT`-значениями
   своей категории и не всем справочником атрибута — и заменяется целиком:
   набор условий это одна команда, а не правка строк.
5. Снятая с публикации страница пропадает и из плиток, и по своему адресу:
   витрина отвечает `LANDING_NOT_FOUND` (404).
6. `updated_at` берётся из `clock.now()`; `created_at` не трогается.

## Errors

| Код | HTTP | Когда |
|---|---|---|
| `VALIDATION_ERROR` | 422 | Форма не прошла границы ввода |
| `LANDING_NOT_FOUND` | 404 | Посадочной с таким идентификатором нет |
| `INVALID_LANDING_SLUG` | 400 | Из заголовка не выводится ни одного символа адреса |
| `INVALID_LANDING_NARROWING` | 400 | Сужение пустое, шире двух атрибутов, чужое или равно всей категории |
| `LANDING_SLUG_TAKEN` | 409 | Адрес занят другой посадочной |
| `CONCURRENT_CHANGE` | 429 | Строку правят в другом окне |
