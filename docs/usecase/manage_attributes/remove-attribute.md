# Удаление атрибута

**Актор:** владелец, установленный Django-презентацией.

Владелец убирает характеристику из справочника вместе со всеми её значениями.

## Input

`AttributeId` путевым параметром.

## Output

`None`.

## Business Rules

1. Атрибут существует — иначе `ATTRIBUTE_NOT_FOUND` (404).
2. Атрибут никому не нужен: ни один товар не объявил по нему значений и ни
   один другой атрибут не назвал его родителем — иначе `ATTRIBUTE_IN_USE`
   (409), и в `meta` два перечня, `products` и `attributes`. Отказ один на
   один вопрос — «кто его ещё держит»: два кода на одну стену владелец читал
   бы дважды (решение 9).
3. Атрибут удаляется вместе со значениями (`CASCADE` на `attribute_values`),
   одна транзакция коммитится. Ошибки нет.

## Errors

| Код | HTTP | Когда |
|---|---|---|
| `ATTRIBUTE_NOT_FOUND` | 404 | Атрибута нет |
| `ATTRIBUTE_IN_USE` | 409 | Атрибут объявлен товарами или назван родителем другого атрибута |
