# Удаление атрибута

**Актор:** владелец, установленный Django-презентацией.

Владелец убирает характеристику из справочника вместе со всеми её значениями.

## Input

`AttributeId` путевым параметром.

## Output

`None`.

## Business Rules

1. Атрибут существует — иначе `ATTRIBUTE_NOT_FOUND` (404).
2. Ни один другой атрибут не назвал его родителем — иначе
   `INVALID_ATTRIBUTE_PARENT` (400): удалив его, мы оставили бы зависимый
   атрибут с висящей ссылкой. Правило доменное и проверяется раньше того,
   что спрашивает у хранилища.
3. Ни один товар не объявил значений по этому атрибуту — иначе
   `ATTRIBUTE_IN_USE` (409), и в `meta` перечислены названия товаров.
4. Атрибут удаляется вместе со значениями (`CASCADE` на `attribute_values`),
   одна транзакция коммитится. Ошибки нет.

## Errors

| Код | HTTP | Когда |
|---|---|---|
| `ATTRIBUTE_NOT_FOUND` | 404 | Атрибута нет |
| `ATTRIBUTE_IN_USE` | 409 | Атрибут объявлен товарами |
| `INVALID_ATTRIBUTE_PARENT` | 400 | Атрибут назван родителем другого атрибута |
