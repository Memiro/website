# Заведение атрибута

**Актор:** владелец, установленный Django-презентацией.

Владелец заводит категории новую характеристику вместе с её значениями:
«подсветка», «форма», «тип полотна». Интерактор зовёт карточка атрибута в
админке (`presentation/django_admin/attribute_card.py`) через мост.

## Input

`CreateAttributeForm`

| Поле | Тип | Смысл |
|---|---|---|
| `category_id` | `UUID` | Раздел, к которому привязан атрибут |
| `name` | `str` | Название атрибута |
| `kind` | `AttributeKind` | Как покупатель его настраивает: списком или числом |
| `parent_ids` | `list[UUID]` | Атрибуты той же категории, от которых он зависит |
| `is_customer_changeable` | `bool` | Меняет ли его покупатель |
| `is_filterable` | `bool` | Строит ли он фильтр каталога |
| `sort_order` | `int` | Порядок владельца |
| `values` | `list[AttributeValueForm]` | Набор значений справочника |

`AttributeValueForm`

| Поле | Тип | Смысл |
|---|---|---|
| `name` | `str` | Название значения |
| `rate_amount` | `Decimal` | Тариф значения |
| `rate_unit` | `Unit` | Единица, в которой значение расходуется |
| `scaled_by_shape` | `bool` | Умножается ли формой |
| `scaled_by_size_surcharge` | `bool` | Умножается ли наценкой за размер |
| `marks_absence` | `bool` | Означает ли отсутствие признака |
| `sort_order` | `int` | Порядок владельца |

## Output

`CreatedAttribute`

| Поле | Тип | Смысл |
|---|---|---|
| `id` | `UUID` | Идентификатор нового атрибута |

## Business Rules

1. Название непустое и не длиннее `MAX_NAME_LENGTH`, значений не больше
   `MAX_ATTRIBUTE_VALUES`, родителей не больше `MAX_ATTRIBUTE_PARENTS`,
   порядок неотрицательный, тариф от нуля до `MAX_RATE_AMOUNT` — иначе
   `VALIDATION_ERROR` (422).
2. Категория существует — иначе `CATEGORY_NOT_FOUND` (404).
3. Каждый родитель — атрибут той же категории; сам себе родителем атрибут
   быть не может, и круга в родстве не образуется — иначе
   `INVALID_ATTRIBUTE_PARENT` (400).
4. У числового атрибута ровно одна строка справочника — иначе
   `INVALID_ATTRIBUTE_VALUE_SET` (400). Сослаться на чужую строку форма
   заведения не может: у её строк нет поля идентификатора, и всякую строку
   нового атрибута выдаёт сам агрегат.
5. У значения с единицей `FACTOR` тариф больше нуля — иначе
   `INVALID_FACTOR_RATE` (400).
6. Атрибут и его значения создаются одной транзакцией, `created_at` и
   `updated_at` берутся одним `clock.now()`. Ошибки нет.

## Errors

| Код | HTTP | Когда |
|---|---|---|
| `VALIDATION_ERROR` | 422 | Форма не прошла границы ввода |
| `CATEGORY_NOT_FOUND` | 404 | Категории нет |
| `INVALID_ATTRIBUTE_PARENT` | 400 | Родитель не той категории, это сам атрибут или родство замкнулось в круг |
| `INVALID_ATTRIBUTE_VALUE_SET` | 400 | Набор значений не описывает справочник этого атрибута |
| `INVALID_FACTOR_RATE` | 400 | У значения с единицей `FACTOR` нулевой коэффициент |
