# Замена набора значений атрибута

**Актор:** владелец, установленный Django-презентацией.

Карточка админки шлёт эту команду первой, а `change_attribute` следом:
отказ на наборе значений оставляет корень таким, каким владелец его застал
(тикет 09).

Владелец правит справочник атрибута: заводит строки, переименовывает,
переставляет, меняет тариф и удаляет ненужные. Набор заменяется целиком одной
командой корня, а не правится построчно (`attribute.md`, правило 13): карточка
атрибута и плоский экран «Материалы и цены» приходят сюда обе, и второй правды
о цене в системе не заводится.

## Input

`ReplaceValuesForm`

| Поле | Тип | Смысл |
|---|---|---|
| `values` | `list[ReplacementValueForm]` | Набор значений целиком — какой должен остаться |

`ReplacementValueForm` — поля [`AttributeValueForm`](create-attribute.md) плюс
`id: UUID | None`: строка справочника, которую эта строка набора оставляет.

Строка с `id` — та, что уже есть: она правится на месте и остаётся объявленной
у товаров. Строка без `id` — новая. Строка, которой в наборе не назвали, —
удаляется.

## Output

`None`.

## Business Rules

1. Границы формы — как при заведении атрибута, иначе `VALIDATION_ERROR` (422).
2. Атрибут существует — иначе `ATTRIBUTE_NOT_FOUND` (404).
3. Набор законен: идентификаторы не повторяются, каждый названный `id` —
   строка **этого** атрибута, у числового атрибута ровно одна строка — иначе
   `INVALID_ATTRIBUTE_VALUE_SET` (400).
4. Ни одну из исчезающих строк не объявил ни один товар — иначе
   `ATTRIBUTE_VALUE_IN_USE` (409), и в `meta` перечислены названия товаров.
   Проверка идёт до базы: `CASCADE` на ссылающихся строках правило не
   заменяет, он лишь убирает мусор за легальным удалением. Условия посадочных
   страниц войдут в тот же перечень, когда таблица посадочных появится
   (тикет 03, Comments).
5. У значения с единицей `FACTOR` тариф больше нуля — иначе
   `INVALID_FACTOR_RATE` (400).
6. Набор заменяется, `updated_at` атрибута двигается последней строкой, одна
   транзакция одного агрегата коммитится. Ошибки нет. Строго после коммита
   публикуется `TariffChanged` с одним `attribute_id`, и подписчик
   [`reprice_products`](../reprice_products/reprice-products.md) пересчитывает
   цены каталога своей транзакцией; его падение эту правку не откатывает
   (ADR-0014).

## Errors

| Код | HTTP | Когда |
|---|---|---|
| `VALIDATION_ERROR` | 422 | Форма не прошла границы ввода |
| `ATTRIBUTE_NOT_FOUND` | 404 | Атрибута нет |
| `INVALID_ATTRIBUTE_VALUE_SET` | 400 | Набор не описывает справочник этого атрибута |
| `ATTRIBUTE_VALUE_IN_USE` | 409 | Удаляемое значение объявлено товарами |
| `INVALID_FACTOR_RATE` | 400 | У значения с единицей `FACTOR` нулевой коэффициент |
