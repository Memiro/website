# Удаление предпосчитанного варианта

**Актор:** владелец, установленный Django-презентацией.

## Input

| Поле | Тип | Смысл |
|---|---|---|
| `product_id` | `ProductId` | Товар, которому принадлежит вариант |
| `variant_id` | `VariantId` | Удаляемый вариант |

## Output

| Тип | Смысл |
|---|---|
| `None` | Тела результата нет |

## Business Rules

1. Товар существует — иначе `PRODUCT_NOT_FOUND` (404).
2. Вариант принадлежит товару — иначе `VARIANT_NOT_FOUND` (404).
3. Вариант удаляется; `price_from` пересчитывается последней строкой в минимум
   оставшихся цен либо `None`; одна транзакция агрегата коммитится. Ошибки нет.

## Errors

| Код | HTTP | Когда |
|---|---|---|
| `PRODUCT_NOT_FOUND` | 404 | Товара нет |
| `VARIANT_NOT_FOUND` | 404 | Варианта у товара нет |
