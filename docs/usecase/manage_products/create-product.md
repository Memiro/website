# Заведение товара

**Актор:** владелец, установленный Django-презентацией.

Владелец заводит в разделе каталога новое изделие: название, публичный адрес,
описание карточки и два переключателя витрины. Интерактор зовёт карточка
товара в админке через мост (тикет 10).

Товар рождается пустым: объявленных значений у него нет — их приносит
[объявление значений](declare-values.md), — и вариантов тоже, поэтому цены он
не показывает (`price_from = None`).

## Input

`CreateProductForm`

| Поле | Тип | Смысл |
|---|---|---|
| `category_id` | `UUID` | Раздел, в котором заводится товар |
| `name` | `str` | Название |
| `slug` | `str` | Адрес в публичном URL; пустой транслитерируется из названия |
| `description` | `str` | Описание на карточке витрины |
| `is_published` | `bool` | Виден ли на витрине |
| `hides_calculated_price` | `bool` | Не называть цену расчёта (ADR-0008) |

## Output

`CreatedProduct`

| Поле | Тип | Смысл |
|---|---|---|
| `id` | `UUID` | Идентификатор нового товара |

## Business Rules

1. Название непустое и не длиннее `MAX_NAME_LENGTH`, описание не длиннее
   `MAX_DESCRIPTION_LENGTH`, адрес — пустой или строчная латиница с цифрами
   через дефис — иначе `VALIDATION_ERROR` (422). Адрес владелец правит руками,
   и форма не переписывает то, что он ввёл: непохожее на адрес она отклоняет.
2. Категория существует — иначе `CATEGORY_NOT_FOUND` (404).
3. Пустой адрес домен выводит из названия транслитерацией; если выводить
   нечего — `INVALID_PRODUCT_SLUG` (400).
4. Адрес свободен по сайту — иначе `PRODUCT_SLUG_TAKEN` (409). Уникальность
   держит база, и проигранная гонка возвращается `CONCURRENT_CHANGE` (429).
5. Товар заводится без объявленных значений и без вариантов: цены у него нет,
   и в сужение по диапазону цены он не попадает.
6. `created_at` и `updated_at` берутся одним `clock.now()`.

## Errors

| Код | HTTP | Когда |
|---|---|---|
| `VALIDATION_ERROR` | 422 | Форма не прошла границы ввода |
| `CATEGORY_NOT_FOUND` | 404 | Раздела нет |
| `INVALID_PRODUCT_SLUG` | 400 | Из названия не выводится ни одного символа адреса |
| `PRODUCT_SLUG_TAKEN` | 409 | Адрес занят другим товаром |
| `CONCURRENT_CHANGE` | 429 | Адрес занял конкурент между проверкой и записью |
