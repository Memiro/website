# Добавление предпосчитанного варианта

**Актор:** владелец, установленный Django-презентацией.

Владелец добавляет товару готовую конфигурацию. Этот срез предоставляет
интерактор; конструктор Django вызывает его в тикете 18.

## Input

`AddVariantForm`

| Поле | Тип | Смысл |
|---|---|---|
| `width_mm` | `int` | Ширина варианта |
| `height_mm` | `int` | Высота варианта |
| `overrides` | `list[VariantOverrideForm]` | Чем вариант отличается от товара |
| `sort_order` | `int` | Порядок владельца |

## Output

`CreatedVariant`

| Поле | Тип | Смысл |
|---|---|---|
| `id` | `UUID` | Идентификатор нового варианта |

## Business Rules

1. Стороны укладываются в application limits, overrides не больше
   `MAX_SELECTIONS`, один атрибут назван не больше раза, а override несёт ровно
   одно из `value_id` и `quantity` — иначе `VALIDATION_ERROR` (422).
2. Товар существует — иначе `PRODUCT_NOT_FOUND` (404).
3. Параметры расчёта существуют — иначе `PRICING_SETTINGS_NOT_FOUND` (404).
4. Каждый override разрешается по справочнику категории товара и соответствует
   виду атрибута — иначе `ATTRIBUTE_VALUE_NOT_FOUND` (404).
5. Получившаяся конфигурация полностью считается — иначе
   `INVALID_VARIANT_CONFIGURATION` (400).
6. Порядок неотрицательный — иначе `INVALID_VARIANT_SORT_ORDER` (400).
7. Того же размера с учётом поворота и того же итогового набора значений
   ещё нет — иначе `DUPLICATE_VARIANT` (409). Override, повторяющий значение
   товара, не делает конфигурацию другой.
8. Цена считается владельческим вопросом к единственному pricing service:
   покупательские гейты не действуют, наценка за размер действует. Ошибки нет.
9. Вариант добавляется, `price_from` пересчитывается последней строкой как
   минимум цен, и одна транзакция одного агрегата коммитится. Ошибки нет.

## Errors

| Код | HTTP | Когда |
|---|---|---|
| `VALIDATION_ERROR` | 422 | Форма не прошла границы ввода |
| `PRODUCT_NOT_FOUND` | 404 | Товара нет |
| `PRICING_SETTINGS_NOT_FOUND` | 404 | Параметры расчёта не заведены |
| `ATTRIBUTE_VALUE_NOT_FOUND` | 404 | Override не принадлежит справочнику товара |
| `INVALID_VARIANT_CONFIGURATION` | 400 | Конфигурацию нельзя посчитать |
| `INVALID_VARIANT_SORT_ORDER` | 400 | Порядок отрицательный |
| `DUPLICATE_VARIANT` | 409 | Такой вариант уже существует |
