# Удаление фотографии товара

**Актор:** владелец, установленный Django-презентацией.

## Input

| Поле | Тип | Смысл |
|---|---|---|
| `product_id` | `ProductId` | Товар, которому принадлежит фотография |
| `key` | `str` | Ключ удаляемой фотографии |

## Output

| Тип | Смысл |
|---|---|
| `None` | Тела результата нет |

## Business Rules

1. Товар существует — иначе `PRODUCT_NOT_FOUND` (404); он берётся под замок.
2. Ключ называет фотографию этого товара — иначе
   `PRODUCT_IMAGE_NOT_FOUND` (404).
3. Фотография уходит из галереи командой `remove_image`, `updated_at`
   двигается последней строкой, и коммитится одна транзакция одного агрегата.
4. Файл убирается из хранилища **после** коммита: витрина читает строку, и
   файл, убранный раньше, оставил бы галерею смотреть в пустоту. Файл,
   который хранилищу не удалось убрать, — мусор, а не ответ владельцу:
   реализация пишет warning и отвечает.

## Errors

| Код | HTTP | Когда |
|---|---|---|
| `PRODUCT_NOT_FOUND` | 404 | Товара нет |
| `PRODUCT_IMAGE_NOT_FOUND` | 404 | Ключ не называет фотографии этого товара |
