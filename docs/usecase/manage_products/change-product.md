# Правка товара

**Актор:** владелец, установленный Django-презентацией.

Владелец правит корень товара: название, адрес, раздел, описание и два
переключателя витрины. Объявленные значения и варианты меняются своими
командами — этот сценарий их не трогает.

## Input

`ChangeProductForm` — те же поля, что у [заведения](create-product.md).

| Поле | Тип | Смысл |
|---|---|---|
| `category_id` | `UUID` | Раздел товара |
| `name` | `str` | Название |
| `slug` | `str` | Адрес в публичном URL; пустой транслитерируется из названия |
| `description` | `str` | Описание на карточке витрины |
| `is_published` | `bool` | Виден ли на витрине |
| `hides_calculated_price` | `bool` | Не называть цену расчёта (ADR-0008) |

## Output

Ничего.

## Business Rules

1. Границы ввода — те же, что у заведения, иначе `VALIDATION_ERROR` (422).
   Правка переписывает корень целиком, поэтому описание и оба переключателя
   обязательны: пропущенное поле сняло бы публикацию или стёрло описание
   молча. Дефолт остаётся только у адреса — пустой значит «выведи заново».
2. Товар существует — иначе `PRODUCT_NOT_FOUND` (404).
3. Раздел, если он меняется, существует — иначе `CATEGORY_NOT_FOUND` (404).
4. Пустой адрес выводится из названия; выводить нечего — `INVALID_PRODUCT_SLUG`
   (400). Смена адреса — смена публичной ссылки, и решает её владелец.
5. Адрес свободен или это собственный адрес товара — иначе
   `PRODUCT_SLUG_TAKEN` (409).
6. Раздел меняется только у пустого товара: пока он объявляет значения или
   держит варианты — `PRODUCT_SECTION_NOT_EMPTY` (409). Владелец сначала
   очищает карточку, потом переносит (`docs/entities/product.md`, правило 16).
7. `updated_at` ставится последней строкой команды.

## Errors

| Код | HTTP | Когда |
|---|---|---|
| `VALIDATION_ERROR` | 422 | Форма не прошла границы ввода |
| `PRODUCT_NOT_FOUND` | 404 | Товара нет |
| `CATEGORY_NOT_FOUND` | 404 | Раздела нет |
| `INVALID_PRODUCT_SLUG` | 400 | Из названия не выводится ни одного символа адреса |
| `PRODUCT_SLUG_TAKEN` | 409 | Адрес занят другим товаром |
| `PRODUCT_SECTION_NOT_EMPTY` | 409 | Товар переносят в другой раздел непустым |
| `LOCK_TIMEOUT` | 429 | Товар правят в другом окне |
| `CONCURRENT_CHANGE` | 429 | Адрес занял конкурент между проверкой и записью |
