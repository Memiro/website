# Список вариантов товара

**Актор:** владелец, установленный Django-презентацией.

Конструктор в карточке товара перерисовывает список вариантов целиком после
каждой правки: «от» на витрине даёт самый дешёвый вариант, и заведённый
вариант меняет пометку у другого.

## Input

| Поле | Тип | Смысл |
|---|---|---|
| `product_id` | `UUID` | Товар, чьи варианты показываются |

## Output

`VariantsList`

| Поле | Тип | Смысл |
|---|---|---|
| `items` | `list[VariantModel]` | Варианты в порядке владельца |
| `total` | `int` | Сколько их |

`VariantModel`

| Поле | Тип | Смысл |
|---|---|---|
| `id` | `UUID` | Идентификатор варианта |
| `width_mm` | `int` | Ширина |
| `height_mm` | `int` | Высота |
| `price` | `Decimal` | Цена варианта |
| `sort_order` | `int` | Порядок владельца |
| `overrides` | `list[VariantOverrideModel]` | Чем вариант отличается от товара, названное словами |
| `sets_product_price` | `bool` | С этого варианта берётся «цена от» витрины |

`VariantOverrideModel`

| Поле | Тип | Смысл |
|---|---|---|
| `attribute_id` | `UUID` | Атрибут, чьё значение заменено |
| `attribute_name` | `str` | Название атрибута |
| `value_id` | `UUID \| null` | Строка справочника, если значение выбрано из него |
| `value_name` | `str \| null` | Название строки справочника |
| `quantity` | `Decimal \| null` | Количество, если атрибут числовой |

## Business Rules

1. Товар существует — иначе `PRODUCT_NOT_FOUND` (404).
2. Варианты идут в порядке владельца — тем же, каким их отдаёт карточка
   витрины. Ошибки нет.
3. `sets_product_price` стоит у вариантов, чья цена равна `price_from` товара:
   «от» на витрине берётся с самого дешёвого. Ошибки нет.
4. Override называется словами атрибута и справочной строки — владелец читает
   отличия, а не идентификаторы. Ошибки нет.

## Errors

| Код | HTTP | Когда |
|---|---|---|
| `PRODUCT_NOT_FOUND` | 404 | Товара нет |
