# Объявление значений товара

**Актор:** владелец, установленный Django-презентацией.

Владелец объявляет, чем товар заполнен по атрибутам своего раздела: полотно,
рама, подсветка, число вырезов. Набор заменяется целиком — атрибут, которого в
наборе нет, у товара не заполнен, и «товар дорос до расчёта» проверяется по
тому, что осталось (`docs/entities/product.md`, правило 9).

## Input

`DeclareValuesForm`

| Поле | Тип | Смысл |
|---|---|---|
| `declarations` | `list[DeclarationForm]` | Набор целиком, каким владелец хочет его видеть |

`DeclarationForm`

| Поле | Тип | Смысл |
|---|---|---|
| `attribute_id` | `UUID` | Атрибут раздела товара |
| `value_id` | `UUID \| None` | Строка справочника этого атрибута |
| `quantity` | `Decimal \| None` | Количество, если атрибут числовой |

## Output

Ничего.

## Business Rules

1. Объявлений не больше `MAX_SELECTIONS`, у каждого ровно одно представление —
   строка справочника или количество, — количество от нуля до `MAX_QUANTITY`, и
   на один атрибут приходится одно объявление; иначе `VALIDATION_ERROR` (422).
2. Товар существует — иначе `PRODUCT_NOT_FOUND` (404).
3. Каждый названный атрибут — атрибут раздела этого товара, а значение —
   строка этого атрибута; иначе `ATTRIBUTE_VALUE_NOT_FOUND` (404).
4. Набор заменяется целиком командой агрегата `declare_values`: не названный
   атрибут остаётся незаполненным, а прежнее объявление по нему уходит.
5. Цены товара команда не трогает: `price_from` выводится из вариантов, и
   пересчёт вариантов под новые объявления владелец запускает сам.
6. `updated_at` ставится последней строкой команды.

## Errors

| Код | HTTP | Когда |
|---|---|---|
| `VALIDATION_ERROR` | 422 | Форма не прошла границы ввода |
| `PRODUCT_NOT_FOUND` | 404 | Товара нет |
| `ATTRIBUTE_VALUE_NOT_FOUND` | 404 | Значения нет, оно чужого атрибута или атрибут не из раздела товара |
| `INVALID_QUANTITY` | 400 | Количество отрицательное |
| `LOCK_TIMEOUT` | 429 | Товар правят в другом окне |
