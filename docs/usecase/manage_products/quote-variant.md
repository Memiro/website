# Цена собираемого варианта

**Актор:** владелец, установленный Django-презентацией.

Владелец видит цену варианта до того, как заведёт его: конструктор в карточке
товара спрашивает ту же цену тем же расчётом, которым она запишется варианту.
Записи здесь нет — это чтение.

## Input

`QuoteVariantForm`

| Поле | Тип | Смысл |
|---|---|---|
| `width_mm` | `int` | Ширина варианта |
| `height_mm` | `int` | Высота варианта |
| `overrides` | `list[VariantOverrideForm]` | Чем вариант отличается от товара |
| `sort_order` | `int` | Порядок владельца |
| `manual_price` | `Decimal \| None` | Цена, вписанная владельцем; пусто — считать (ADR-0017) |

## Output

`QuotedVariant`

| Поле | Тип | Смысл |
|---|---|---|
| `price` | `Decimal` | Цена, с которой вариант запишется |

## Business Rules

1. Границы ввода те же, что у заведения варианта — иначе `VALIDATION_ERROR`
   (422).
2. Товар существует — иначе `PRODUCT_NOT_FOUND` (404).
3. Параметры расчёта существуют — иначе `PRICING_SETTINGS_NOT_FOUND` (404).
4. Каждый override разрешается по справочнику раздела товара и заменяет
   объявленное товаром значение — иначе `ATTRIBUTE_VALUE_NOT_FOUND` (404).
5. Получившаяся конфигурация полностью считается **или** цена вписана — иначе
   `INVALID_VARIANT_CONFIGURATION` (400). Владелец узнаёт об этом до того, как
   нажмёт «Добавить», тем же отказом, каким его встретила бы запись.
6. Цена — ответ единственного pricing service на владельческий вопрос:
   покупательские гейты не действуют, наценка за размер действует, и число
   совпадает с тем, которое запишет `add_variant`. Вписанной ценой вопрос
   отвечает ею самой — это и есть то, что запишется (ADR-0017); панель в этом
   режиме за ценой не ходит вовсе. Ошибки нет.

## Errors

| Код | HTTP | Когда |
|---|---|---|
| `VALIDATION_ERROR` | 422 | Форма не прошла границы ввода |
| `PRODUCT_NOT_FOUND` | 404 | Товара нет |
| `PRICING_SETTINGS_NOT_FOUND` | 404 | Параметры расчёта не заведены |
| `ATTRIBUTE_VALUE_NOT_FOUND` | 404 | Override не принадлежит справочнику товара или его атрибут у товара не объявлен |
| `INVALID_VARIANT_CONFIGURATION` | 400 | Конфигурацию нельзя посчитать, и цена не вписана |
