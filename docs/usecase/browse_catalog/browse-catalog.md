# Просмотреть каталог

## Назначение

Анонимный посетитель получает категории, опубликованные товары выбранной
категории и опубликованную карточку товара по публичным slug. Чтение не меняет
каталог и не пересчитывает цену.

## Актор

Анонимный посетитель витрины.

## Вход и выход

| Операция | Вход | Выход |
|---|---|---|
| Список категорий | Нет | `CategoryModel[]`: название и slug |
| Товары категории | `category_slug` | `CatalogProducts`: категория и `CatalogProductModel[]` |
| Карточка товара | `product_slug` | `ProductModel`: идентификатор товара, атрибуты, варианты, фото-ключи |

`CatalogProductModel` несёт `name`, `slug`, `price_from` и `image_keys`.
Карточка несёт UUID `id`, нужный только для следующего публичного вопроса о
цене, а также `description`, объявленные значения атрибутов и варианты с
размерами, переопределениями и заранее посчитанной ценой.

## Business Rules

1. Список содержит только категории, в которых есть хотя бы один
   опубликованный товар, и следует `sort_order` владельца. Ошибки нет.
2. Slug категории разрешается в категорию; неизвестный slug отклоняется с
   `CATEGORY_NOT_FOUND` (404).
3. Список категории содержит только опубликованные товары. Цена «от» читается
   из сохранённого производного `price_from`, а не пересчитывается. Ошибки нет.
4. Slug товара разрешается только в опубликованный товар; отсутствующий и
   неопубликованный товар отклоняются одинаково с `PRODUCT_NOT_FOUND` (404).
5. Карточка возвращает UUID товара, описание, фото-ключи, объявленные
   атрибуты и их значения в порядке владельца. UUID передаётся в
   `POST /api/calculate`; он не раскрывает устройство цены. Ошибки нет.
6. Варианты карточки возвращаются в `sort_order` владельца. Ошибки нет.
7. Погашенная цена расчёта не скрывает опубликованный товар: `price_from`
   предпосчитанных вариантов остаётся доступной. Ошибки нет.
8. Публичный JSON не раскрывает ставку, единицу расхода, коэффициент или
   строки внутреннего расчёта. Ошибки нет.

## Errors

| Код | HTTP | Когда |
|---|---|---|
| `CATEGORY_NOT_FOUND` | 404 | Slug категории отсутствует |
| `PRODUCT_NOT_FOUND` | 404 | Slug товара отсутствует или товар не опубликован |
