# Карточка товара

**Актор:** анонимный посетитель витрины.

Посетитель получает опубликованную карточку товара по публичному slug. Чтение
не меняет каталог и не пересчитывает цену.

## Input

| Поле | Тип | Смысл |
|---|---|---|
| `product_slug` | `str` | Публичный slug товара |

## Output

`ProductModel`

| Поле | Тип | Смысл |
|---|---|---|
| `id` | `UUID` | Идентификатор товара для следующего вопроса о цене |
| `name`, `slug` | `str` | Название и публичный адрес |
| `description` | `str` | Описание товара |
| `price_from` | `Decimal \| None` | Сохранённая цена «от» предпосчитанных вариантов |
| `image_keys` | `list[str]` | Ключи фотографий в порядке владельца |
| `attributes` | `list[ProductAttribute]` | Объявленные атрибуты: идентификатор, название, вид (`kind`) и значения |
| `variants` | `list[ProductVariant]` | Предпосчитанные варианты с размерами, переопределениями и ценой |

## Business Rules

1. Slug разрешается только в опубликованный товар; отсутствующий и
   неопубликованный товар отклоняются одинаково с `PRODUCT_NOT_FOUND` (404) —
   витрина не узнаёт о существовании скрытого товара.
2. Карточка возвращает UUID товара, описание, фото-ключи, объявленные атрибуты
   и их значения в порядке владельца. UUID передаётся в `POST /api/calculate`;
   он не раскрывает устройство цены. Ошибки нет.
3. Каждый атрибут карточки называет свой вид: `select` — покупатель выбирает
   строку справочника, `number` — вводит число. Витрина рисует поле по виду,
   а не по числу значений. У числового атрибута единственная строка справочника
   несёт тариф, а не пункт списка: карточка отдаёт её без идентификатора и с
   объявленным товаром количеством (`quantity`), чтобы поле открылось на том
   числе, которое уже посчитано в цене. Ошибки нет.
4. Варианты возвращаются в `sort_order` владельца. Ошибки нет.
5. Погашенная для покупателя цена расчёта не скрывает опубликованный товар:
   `price_from` и предпосчитанные варианты остаются доступными. Ошибки нет.
6. Публичный JSON не раскрывает ставку, единицу расхода, коэффициент или
   строки внутреннего расчёта. Ошибки нет.

## Errors

| Код | HTTP | Когда |
|---|---|---|
| `PRODUCT_NOT_FOUND` | 404 | Slug товара отсутствует или товар не опубликован |
