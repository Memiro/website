# Список посадочных страниц

**Актор:** анонимный посетитель витрины.

Посетитель получает посадочные, которыми набираются плитки главной и каталога.
Сами страницы описывает [«Посадочная страница»](read-landing.md).

## Input

Нет.

## Output

`LandingsList` — конверт `{items, total, page}`.

| Поле | Тип | Смысл |
|---|---|---|
| `items` | `list[LandingSummary]` | Страница посадочных: `slug`, `heading`, `updated_at` и `image` |
| `image` | `ImageModel \| None` | Фотография плитки: `{key, variants: [{key, width}]}`. Нет фотографий — `null`, и витрина рисует заглушку |
| `total` | `int` | Сколько посадочных подходит всего |
| `page` | `int` | Номер страницы (пока всегда первая: витрина берёт список целиком) |

## Business Rules

1. Список содержит только опубликованные посадочные: снятая с публикации не
   попадает и в плитки. Ошибки нет.
2. Посадочные идут в `sort_order` владельца — тем же порядком, что и на
   странице каждой из них. Ошибки нет.
3. Фотография плитки — первая фотография самого дешёвого опубликованного
   товара, который оставляет сужение самой посадочной: две посадочные одной
   категории показывают разные зеркала. Сужение читается тем же правилом, что
   и в боковой панели. Ошибки нет.
4. Пока посадочных нет, витрина набирает плитки из категорий: пустой список —
   это пустой конверт, а не ошибка.

## Errors

Отказов нет.
