# Список работ

**Актор:** анонимный посетитель витрины.

Посетитель получает галерею «Наши работы» — фотографии установок, которые
владелец завёл в админке ([«Работа заводится»](../manage_works/create-work.md)).

## Input

Нет.

## Output

`WorksList` — конверт `{items, total, page}`.

| Поле | Тип | Смысл |
|---|---|---|
| `items` | `list[WorkModel]` | Страница работ: `photo_key`, `title`, `description`, `product` |
| `total` | `int` | Столько же, сколько в `items`: витрина берёт галерею целиком |
| `page` | `int` | Номер страницы (пока всегда первая: витрина берёт галерею целиком) |

`product` — либо `null`, либо `{category_slug, slug}`: адрес карточки зеркала
с фотографии.

## Business Rules

1. В галерею попадают только опубликованные работы: черновик владельца
   витрина не показывает. Ошибки нет.
2. Работы идут в `sort_order` владельца — тем же порядком, что и в списке
   админки. Ошибки нет.
3. `product` заполнен, только пока каталог продаёт зеркало с фотографии:
   работа без товара (в том числе та, чей товар удалён — связь обнулилась, и
   работа ничем не отличается от заведённой без товара) и работа со снятым с
   публикации товаром отдаются без адреса — витрина не рассказывает о
   скрытом. Ошибки нет.
4. Пустая галерея — пустой конверт, а не ошибка: витрина сама уводит
   посетителя в каталог.

## Errors

Отказов нет.
