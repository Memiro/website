# Товары категории

**Актор:** анонимный посетитель витрины.

Посетитель получает опубликованные товары выбранной категории по публичному
slug. Чтение не меняет каталог и не пересчитывает цену.

## Input

| Поле | Тип | Смысл |
|---|---|---|
| `category_slug` | `str` | Публичный slug категории из списка категорий |

## Output

`ProductsList` — конверт `{items, total, page}`.

| Поле | Тип | Смысл |
|---|---|---|
| `items` | `list[ProductSummary]` | Страница товаров: `name`, `slug`, `price_from`, `image_keys` |
| `total` | `int` | Сколько товаров подходит всего |
| `page` | `int` | Номер страницы (пока всегда первая) |

## Business Rules

1. Slug категории разрешается в категорию; неизвестный slug отклоняется с
   `CATEGORY_NOT_FOUND` (404).
2. Список содержит только опубликованные товары: существующая категория, в
   которой все товары сняты с публикации, отвечает пустым конвертом, а не
   отказом. Ошибки нет.
3. Список содержит только товары этой категории, отсортированные по названию.
   Ошибки нет.
4. Цена «от» читается из сохранённого производного `price_from` товара, а не
   пересчитывается на чтении. Фото-ключи идут в порядке владельца. Ошибки нет.
5. Публичный JSON не раскрывает ставку, единицу расхода, коэффициент или
   строки внутреннего расчёта. Ошибки нет.

## Errors

| Код | HTTP | Когда |
|---|---|---|
| `CATEGORY_NOT_FOUND` | 404 | Slug категории отсутствует |
