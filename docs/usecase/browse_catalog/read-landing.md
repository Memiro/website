# Посадочная страница

**Актор:** анонимный посетитель витрины (и поисковый робот).

Посадочная — вручную заведённое сужение одной категории со своим адресом,
заголовком и текстом (ADR-0003). Индексируется то, что написал владелец, а не
строка запроса, которую собрал робот.

## Input

| Поле | Тип | Смысл |
|---|---|---|
| `slug` | `str` | Публичный адрес посадочной в корне сайта |

## Output

`LandingModel`

| Поле | Тип | Смысл |
|---|---|---|
| `slug`, `heading` | `str` | Адрес и заголовок страницы |
| `title`, `description` | `str` | Мета-заголовок и мета-описание |
| `text` | `str` | SEO-текст владельца; пустой не печатается |
| `category_slug`, `category_name` | `str` | Категория, которую посадочная сужает |
| `values` | `list[UUID]` | Значения, которыми сужается выдача |

Список для плиток витрины отдаёт `ListLandings` — конверт `{items, total, page}`
из `LandingSummary` (`slug`, `heading`).

## Business Rules

1. Посадочная сужает ровно одну категорию: это тип товара со своим набором
   атрибутов, и сужение чужими значениями было бы пустой страницей. Ошибки нет.
2. Значения сужения читаются тем же правилом, что и фильтры: одного атрибута —
   по ИЛИ, разных — по И. Отдельной реализации у посадочной нет, иначе
   индексируемая страница показывала бы не то, что сайдбар (ADR-0003).
   Ошибки нет.
3. Снятая с публикации посадочная отвечает так же, как несуществующая:
   `LANDING_NOT_FOUND` (404) — витрина не сообщает о скрытых страницах.
4. Посадочные живут в корне сайта, и занятый адрес достаётся настоящей
   странице: маршрут посадочной разбирается последним. Ошибки нет.
5. Порядок плиток — `sort_order` владельца. Ошибки нет.

## Errors

| Код | HTTP | Когда |
|---|---|---|
| `LANDING_NOT_FOUND` | 404 | Slug не принадлежит опубликованной посадочной |
