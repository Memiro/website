# Список категорий каталога

**Актор:** анонимный посетитель витрины.

Посетитель получает категории, в которых есть что показать. Чтение не меняет
каталог и не пересчитывает цену.

## Input

Нет.

## Output

`CategoriesList` — конверт `{items, total, page}`.

| Поле | Тип | Смысл |
|---|---|---|
| `items` | `list[CategoryModel]` | Страница категорий: `name`, `slug`, `updated_at` и `image` |
| `image` | `ImageModel \| None` | Фотография плитки: `{key, variants: [{key, width}]}`. Нет фотографий — `null`, и витрина рисует заглушку |
| `total` | `int` | Сколько категорий подходит всего |
| `page` | `int` | Номер страницы (пока всегда первая: витрина берёт список целиком) |

## Business Rules

1. Список содержит только категории, на которых висит хотя бы один
   опубликованный товар. Ошибки нет.
2. Категории идут в `sort_order` владельца. Ошибки нет.
3. Фотография плитки — первая фотография самого дешёвого опубликованного
   товара категории. Величина выводится из уже имеющихся данных, как
   `price_from`: своего поля у категории нет. Порядок товаров на неё не
   влияет — главная выглядит одинаково изо дня в день. Ни одной фотографии —
   `null`. Ошибки нет.
4. Публичный JSON не раскрывает ставку, единицу расхода, коэффициент или
   строки внутреннего расчёта. Ошибки нет.

## Errors

Отказов нет: пустой каталог — это пустой конверт, а не ошибка.
