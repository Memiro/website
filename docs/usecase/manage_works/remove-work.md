# Удаление работы

**Актор:** владелец, установленный Django-презентацией.

Владелец убирает работу из галереи. Интерактор зовёт карточка работы в
админке через мост.

## Input

`work_id: UUID`

## Output

Ничего.

## Business Rules

Правила идут в порядке, в котором их проверяет интерактор.

1. Работа существует — иначе `WORK_NOT_FOUND` (404).
2. Строка удаляется и коммитится, и только после этого фотография уходит с
   тома: файл, удалённый раньше строки, оставил бы галерею с картинкой в
   никуда.
3. Файл, которого на томе уже нет, — не отказ владельцу: строки, которая его
   называла, больше нет.

## Errors

| Код | HTTP | Когда |
|---|---|---|
| `WORK_NOT_FOUND` | 404 | Работы с названным идентификатором нет |
