# Заведение работы

**Актор:** владелец, установленный Django-презентацией.

Владелец заводит работу — фотографию реальной установки изделия у клиента,
из которых собирается галерея «Наши работы» (`CONTEXT.md`). Правил у работы
нет и сущности она не получает (решение 49), но фотография — это файл на
томе, и отказ базы обязан забрать его обратно: ради этого правила работа
заводится интерактором, а не прямым CRUD. Интерактор зовёт карточка работы в
админке через мост.

## Input

`CreateWorkForm`

| Поле | Тип | Смысл |
|---|---|---|
| `photo` | `PhotoForm` | Имя файла и байты фотографии; ключ выдаёт хранилище |
| `product_id` | `UUID \| None` | Зеркало с фотографии, пока каталог его продаёт |
| `title` | `str` | Подпись под фотографией, она же `alt` картинки |
| `description` | `str` | Абзац о том, что и где ставили; пустой не печатается |
| `is_published` | `bool` | Черновик витрине не показывается |
| `sort_order` | `int` | Место в галерее |

## Output

`CreatedWork`

| Поле | Тип | Смысл |
|---|---|---|
| `id` | `UUID` | Идентификатор новой работы |

## Business Rules

Правила идут в порядке, в котором их проверяет интерактор.

1. Заголовок непустой и не длиннее `MAX_NAME_LENGTH`, описание не длиннее
   `MAX_DESCRIPTION_LENGTH`, порядок неотрицателен, файл не тяжелее
   `MAX_IMAGE_BYTES` и назван одним из `IMAGE_EXTENSIONS` — иначе
   `VALIDATION_ERROR` (422).
2. Названный товар существует — иначе `PRODUCT_NOT_FOUND` (404). Работа без
   товара — это фотография без ссылки, а не отказ.
3. Файл пишется на том до строки: ключ выдаёт хранилище, в базу едет ключ, а
   не путь адаптера.
4. Ключ, который хранилище выдало второй раз, называет чужую живую строку:
   удалить файл значило бы забрать чужую фотографию, поэтому это `RuntimeError`
   (500), а не отказ владельцу.
5. Отказ базы после записи файла забирает файл обратно: фотография, которую
   не называет ни одна строка, осталась бы на томе навсегда.

## Errors

| Код | HTTP | Когда |
|---|---|---|
| `VALIDATION_ERROR` | 422 | Форма не прошла границы ввода |
| `PRODUCT_NOT_FOUND` | 404 | Товара с названным идентификатором нет |
| `INTERNAL_ERROR` | 500 | Хранилище выдало ключ живой строки |
