# Отправить заявку

## Назначение

Посетитель отправляет менеджеру подборку зеркал либо свободную форму. Заявка
сохраняет снимок каждой позиции и не является заказом, оплатой или резервом.

## Актор

Анонимный посетитель витрины.

## Вход

| Поле | Тип | Смысл |
|---|---|---|
| `source` | `InquirySource` | `SELECTION` или `FREE_FORM` |
| `name`, `phone`, `email` | строки | Контакты посетителя |
| `consent` | `bool` | Согласие на обработку ПД |
| `comment` | `str` | Текст только свободной формы |
| `items` | `InquiryItemForm[]` | Позиции подборки |

Позиция подборки содержит идентификатор товара, габариты, выбранные значения и
личное пожелание. Она не принимает цену, название товара или вердикт от
браузера.

## Выход

| Поле | Тип | Смысл |
|---|---|---|
| `id` | `InquiryId` | Идентификатор сохранённой заявки |

## Правила

1. Согласие обязательно; без него заявка отклоняется с `CONSENT_REQUIRED`.
   Сервер записывает действующую редакцию согласия.
2. Новые заявки принимают только источники `SELECTION` и `FREE_FORM`;
   `PRODUCT_CARD` отклоняется с `INQUIRY_SOURCE_NOT_ACCEPTED`.
3. У `SELECTION` есть хотя бы одна позиция; пустая подборка отклоняется с
   `EMPTY_INQUIRY`. У `FREE_FORM` позиций нет, а комментарий остаётся только
   у неё.
4. Для каждой позиции сервер загружает товар и актуальный словарь, повторно
   считает конфигурацию тем же доменным сервисом, что и витрина, и сохраняет
   цену и вердикт. Несуществующий товар отклоняется с `PRODUCT_NOT_FOUND`.
5. Позиция сохраняет `product_id` только как ссылку; название товара, имена
   выбранных значений, габариты, цену и вердикт — снимком. Цена, переданная
   браузером, не принимается.
6. Вердикт `BEYOND_LIMITS` не отклоняет позицию: заявка сохраняется вместе с
   её личным пожеланием и снимком без цены.
7. Снимок позиции никогда не пересчитывается после отправки, даже если тариф
   или справочник изменились.
8. Заявка с позициями сохраняется одной транзакцией агрегата `Inquiry`.
   Уведомление менеджеру не входит в этот срез.

## Ошибки

| Код | HTTP | Причина |
|---|---|---|
| `CONSENT_REQUIRED` | 400 | Посетитель не согласился на обработку ПД |
| `INQUIRY_SOURCE_NOT_ACCEPTED` | 400 | Новый запрос использовал исторический источник |
| `EMPTY_INQUIRY` | 400 | Подборка не содержит позиции |
| `INVALID_INQUIRY_CONTENTS` | 400 | Комментарий или позиции не соответствуют источнику заявки |
| `PRODUCT_NOT_FOUND` | 404 | Позиция назвала отсутствующий товар |
| `ATTRIBUTE_VALUE_NOT_FOUND` | 404 | Выбор не принадлежит товару или справочнику |
| `VALIDATION_ERROR` | 422 | Вход не прошёл границы формы |
